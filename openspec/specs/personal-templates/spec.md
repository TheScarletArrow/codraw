# personal-templates Specification

## Purpose
Даёт пользователю приватную библиотеку своих схем: сохранить доску или выделенное как шаблон и затем создавать из него новые доски и вставлять его страницы независимыми копиями.

## Requirements

### Requirement: Приватная библиотека шаблонов
Система SHALL хранить личные шаблоны с названием, описанием, схемой и датами создания и изменения. Только владелец SHALL читать, изменять и удалять шаблон. Список SHALL отдавать метаданные без содержимого схемы.

#### Scenario: Другой пользователь открывает шаблон
- **WHEN** другой пользователь запрашивает, изменяет или удаляет шаблон
- **THEN** API отвечает 404, а его список не содержит чужой шаблон

#### Scenario: Гость входит в аккаунт
- **WHEN** владелец гостевых шаблонов входит через провайдера
- **THEN** его шаблоны переходят в вошедший аккаунт и сохраняют схему

### Requirement: Ограничения шаблонов
Система SHALL допускать до 50 шаблонов, название длиной 1–200 символов, описание до 1000 символов и XML до 8 МиБ. XML SHALL быть файлом draw.io без DTD и внешних сущностей. При достижении лимита создание SHALL отвечать 409 с лимитом; изменение существующего шаблона SHALL оставаться доступным.

#### Scenario: Достигнут лимит
- **WHEN** пользователь создаёт 51-й шаблон
- **THEN** API отвечает 409 и существующие шаблоны сохраняются

#### Scenario: Некорректная схема
- **WHEN** запрос содержит некорректный XML или внешние сущности
- **THEN** API отвечает 400 без сохранения; файл больше 8 МиБ получает 413

### Requirement: Переносимое сохранение
Frontend SHALL сохранять все страницы доски либо выделение текущей страницы с вложенными элементами и внутренними связями. Шаблон SHALL включать копии изображений исходной доски. Комментарии, история, авторство и статусы ревью SHALL не входить в копию.

#### Scenario: Сохранение выделения
- **WHEN** пользователь сохраняет выделенные элементы
- **THEN** шаблон содержит их вложенные элементы, связи между ними и подписи связей; остальные элементы не копируются

#### Scenario: Изображение недоступно
- **WHEN** изображение исходной доски невозможно скопировать
- **THEN** сохранение сообщает об ошибке и не создаёт шаблон с неработающим изображением

### Requirement: Использование и управление шаблоном
Пользователь SHALL создавать новую доску из всех страниц шаблона, вставлять выбранную страницу в редактируемую доску, изменять название и описание, обновлять схему и удалять шаблон с подтверждением. Каждое использование SHALL создавать независимые идентификаторы страниц, ячеек и общих элементов, сохраняя внутренние связи и переходы. Вставка SHALL быть одним действием отмены.

#### Scenario: Повторное использование
- **WHEN** пользователь использует один шаблон дважды
- **THEN** копии независимы от шаблона, исходной доски и друг друга

#### Scenario: Удаление шаблона
- **WHEN** владелец подтверждает удаление
- **THEN** шаблон удаляется, созданные из него доски сохраняются
