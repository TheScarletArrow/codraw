# Proposal

## Why

Новое поле таблицы пустое и потому невидимо: строка без текста, а двойной щелчок по ней открывает ввод нулевой
ширины без курсора — кажется, что назвать поле нельзя. Свойства поля (тип, `NULL`/`NOT NULL`, PK, UNIQUE) задаются
только на панели инструментов наверху, далеко от поля, с которым работает участник.

## What Changes

- Пустое поле показывает серую заглушку «имя поля» (только на холсте, не в данных и не в экспорте).
- Ввод имени поля — шириной не меньше колонки имён, с подсказкой «имя поля», пока пусто.
- При выделении одного поля рядом с таблицей, на высоте поля, появляется плашка свойств: «Тип» со списком типов СУБД,
  `NULL`/`NOT NULL`, PK, UNIQUE — те же элементы и то же поведение, что на панели инструментов, которая остаётся.

## Capabilities

### New Capabilities

- нет

### Modified Capabilities

- `diagram-shapes`: заглушка пустого поля, заметный ввод имени, плашка свойств поля рядом с таблицей.

## Impact

- `frontend`: `diagram/tableShapes.ts` (заглушка), `diagram/editor.ts` (ввод имени, состояние выделенного поля),
  общий компонент свойств поля из `diagram/TableTools.tsx`, новая плашка `diagram/FieldPopover.tsx`, `pages/BoardPage.tsx`.
- `backend`, `collab`, данные доски не меняются.
