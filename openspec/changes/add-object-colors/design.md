## Context

Стиль ячейки хранится в Yjs как `Y.Map` ключей, а связка Yjs ↔ maxGraph уже переносит любые изменения стиля.
Не хватает интерфейса: панель инструментов умеет только undo, масштаб, поля таблицы и маркеры связей.
Требования — в `specs/`.

## Goals / Non-Goals

**Goals:**

- Перекраска выделенных фигур и связей одним действием и одним шагом undo.
- Разные цвета одного объекта, изменённые разными участниками одновременно, не перетирают друг друга.

**Non-Goals:**

- Прозрачность, градиенты, тени, толщина и стиль линии, шрифт — отдельные изменения.
- Сохранение последних использованных цветов.
- Цвет тела таблицы (`swimlaneFillColor`): «Заливка» таблицы красит её заголовок, как в draw.io.

## Decisions

### Ключи стиля

- «Заливка», «Линия», «Текст» — ключи `fillColor`, `strokeColor`, `fontColor`, значения — `#rrggbb` или `none`,
  как в draw.io. Каждый — отдельный ключ `Y.Map` стиля, поэтому одновременная смена разных цветов не
  конфликтует.
- Редактор меняет цвет через `graph.setCellStyles` для всех подходящих выделенных ячеек в одном изменении
  модели: это одна транзакция Yjs и один шаг undo. Заливка применяется только к фигурам.
- Текущий цвет — значение из стиля ячейки, а если его там нет — из стиля по умолчанию для фигур или связей.
  Если у выделенных объектов цвета разные, состояние редактора отдаёт `null`.

### Выбор цвета

- Кнопка на панели показывает текущий цвет квадратиком и открывает всплывающую палитру: 8 светлых и
  8 тёмных цветов из стандартной палитры draw.io, «Без заливки» или «Без линии» и «Свой цвет».
- Всплывающее окно — `Popover` из Radix в стиле shadcn/ui: фокус, Escape и щелчок снаружи уже решены.
  Альтернатива — своё окно на `div`. Отклонена: пришлось бы повторить доступность и закрытие.
- «Свой цвет» — `<input type="color">`. Цвет применяется по событию `change`, а не `input`: пока
  пользователь водит по палитре браузера, документ не получает десятки изменений и шагов undo.

## Risks / Trade-offs

- [Тёмный текст на тёмной заливке нечитаем] → палитра разделена на светлые цвета для заливки и тёмные для
  линий и текста; контраст пользователь выбирает сам.
- [Системный выбор цвета выглядит по-разному в браузерах] → это только способ задать произвольный цвет,
  основной выбор — палитра.
