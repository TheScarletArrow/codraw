# Proposal

## Why

Схему, которую собрали быстро — из шаблона, вставкой из draw.io или по ходу обсуждения, — потом долго расставляют
руками: двигают фигуры, чтобы связи не пересекались, выравнивают ряды. В draw.io для этого есть меню «Упорядочить» со
старыми алгоритмами mxGraph, которые плохо справляются со связями и рамками. Автораскладка в один щелчок, которая
понимает таблицы, группы и рамки C4 и Kubernetes, превращает «набросал как попало» в аккуратную схему — и понадобится
импорту из SQL и Mermaid, где у фигур нет своих мест.

## What Changes

- Кнопка «Автораскладка» на панели инструментов: «Слева направо» и «Сверху вниз». Раскладывает выделенное, а без
  выделения — всю страницу; Ctrl+Shift+L (на macOS — Cmd+Shift+L) — «Слева направо».
- Раскладка слоями (ELK Layered): связанные фигуры встают слоями по направлению, с наименьшим числом пересечений связей;
  несвязанные — рядом. Разложенное остаётся на месте своего левого верхнего угла, раскладка — один шаг отмены, и все
  участники видят результат сразу.
- Таблица раскладывается целиком, связь между полями считается связью таблиц; группа — целиком; изгибы связей между
  разложенными фигурами убираются, чтобы линии проложились заново.
- Рамки («Граница», граница C4, кластер Kubernetes) держат свои фигуры: фигуры внутри рамки раскладываются внутри неё,
  а рамка подстраивает размер под них.
- Библиотека раскладки загружается при первой раскладке, а не с редактором.

## Capabilities

### New Capabilities

- `auto-layout`: автоматическая раскладка страницы или выделенного слоями, с таблицами, группами и рамками.

### Modified Capabilities

- нет

## Impact

- `frontend`: зависимость `elkjs` (EPL-2.0, без изменений, отдельный чанк), модуль `diagram/layout.ts` (модель →
  граф ELK → геометрия), команда редактора `autoLayout`, кнопка панели инструментов, клавиша, справка по клавишам.
- `docs/adr/0003-auto-layout.md` — выбор ELK.
- `backend`, `collab` не меняются: раскладка — обычная правка документа.
