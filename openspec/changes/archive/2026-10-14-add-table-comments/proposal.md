# Proposal

## Why

Имя таблицы редко говорит всё: `accounts` — это клиенты или учётные записи сотрудников, `events` — журнал или очередь.
В базе на это есть `COMMENT ON TABLE`, но на доске пояснение сейчас некуда положить: его пишут стикером рядом, который
отрывается от таблицы при раскладке, а импорт SQL молча выбрасывает комментарии из DDL и дампов.

## What Changes

- У таблицы (и у представления) появляется комментарий — маленькая приглушённая строка под названием в заголовке.
  Заголовок с комментарием выше на эту строку; без комментария таблица выглядит как прежде. Строка видна всем
  участникам, в режиме «Просмотр» и в выгрузке в изображение.
- Выделенная таблица или её поле показывает на панели инструментов поле «Комментарий»: Enter или уход из поля
  применяют текст одним шагом отмены у всех участников, Escape возвращает прежний, пустой текст убирает комментарий.
- Автоширина таблицы учитывает комментарий до предела ширины; длиннее — строка обрезается многоточием, а весь
  комментарий виден в подсказке над таблицей.
- Комментарий переносится копированием, шаблонами, версиями, файлами `.codraw` и `.drawio` (атрибутом `<object>`, как
  запрос представления), находится поиском по доске и называется в «Изменениях с прошлого визита».
- Импорт SQL делает комментарием таблицы `COMMENT ON TABLE` (и `VIEW`, `MATERIALIZED VIEW`) PostgreSQL и Oracle и
  `COMMENT [=] '…'` в параметрах таблицы MySQL и ClickHouse; `IS NULL` убирает комментарий. Выгрузка SQL пишет
  `COMMENT ON TABLE … IS '…';` сразу после `CREATE TABLE` (и `CREATE VIEW`).
- Схема из живой базы PostgreSQL приходит с комментариями таблиц и представлений.

## Capabilities

### New Capabilities

- `table-comments`: комментарий таблицы под её названием — вид, правка, ширина, подсказка, перенос в копиях и файлах,
  комментарий в SQL.

### Modified Capabilities

- `sql-schema`: `COMMENT ON TABLE` таблиц импорта перестаёт быть служебным оператором и становится комментарием;
  выгрузка SQL пишет комментарии.
- `live-schema-import`: DDL из живой базы содержит `COMMENT ON` таблиц и представлений.
- `canvas-search`: поиск по доске находит таблицу по её комментарию.

## Impact

- `frontend`: новый `diagram/tableComments.ts` (ключ стиля, чтение, место строки), `diagram/tableShapes.ts`
  (рисование строки), `diagram/editor.ts` (высота заголовка, автоширина, подсказка, `setTableComment`,
  `EditorState.tableComment`), `diagram/TableTools.tsx`, `diagram/merge.ts`, `templates/builder.ts`,
  `drawio/style.ts`, `drawio/parse.ts`, `drawio/serialize.ts`, `boardFile/read.ts`, `diagram/canvasSearch.ts`,
  `board/changes.ts`, `proposals/schemaImportUpdate.ts`, `sql/parseSql.ts`, `sql/erDiagram.ts`, справка и «Что нового».
- `backend`: `PostgresSchemaReader` читает `obj_description` таблиц и представлений.
- `collab` не меняется; схемы БД, API и зависимостей изменение не трогает.
- Вне изменения: комментарии столбцов (`COMMENT ON COLUMN`), комментарии в Mermaid и в «Миграции SQL»,
  `sp_addextendedproperty` SQL Server.
