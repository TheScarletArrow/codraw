# Proposal

## Why

На доске с десятками фигур CoDraw не помогает навести порядок: фигуры выравниваются только перетаскиванием на глаз,
промежутки между ними неравные, а набор фигур, который логически одно целое (сервис с базой и очередью), приходится
двигать и копировать по одной. Большую схему, в том числе импортированную из draw.io, нельзя увидеть целиком одним
действием — только подбирать масштаб кнопками.

## What Changes

- `frontend`: «Показать всё» на панели инструментов и Ctrl+Shift+H — масштаб и прокрутка, при которых видна вся
  страница, но не крупнее 100%.
- `frontend`: «Выравнивание» на панели инструментов, когда выделено несколько фигур: по левому краю, по центру, по
  правому краю, по верхнему краю, по середине, по нижнему краю; при трёх и более фигурах — «Распределить по
  горизонтали» и «Распределить по вертикали» с равными промежутками.
- `frontend`: группировка: «Сгруппировать» (Ctrl+G) объединяет выделенные фигуры и связи между ними в группу, которая
  выделяется, перемещается, копируется и удаляется целиком; «Разгруппировать» (Ctrl+Shift+G) возвращает их на
  страницу. Пункты есть и в меню правого щелчка.
- Группы сохраняются в `.drawio` как группы draw.io и читаются из него.
- Каждое действие — один шаг отмены, видимый всем участникам; у участника с правом просмотра этих действий нет,
  кроме «Показать всё».

## Capabilities

### New Capabilities

- `shape-arrangement`: выравнивание, распределение и группировка фигур.

### Modified Capabilities

- `diagram-editing`: масштаб и прокрутка дополняются «Показать всё».
- `canvas-context-menu`: меню нескольких выделенных элементов получает «Сгруппировать», появляется меню группы с
  «Разгруппировать».

## Impact

- `frontend`: `editor.ts` (команды, состояние, клавиши, выделение рамкой и копирование групп), `EditorToolbar.tsx`
  и новый компонент «Выравнивание», `canvasMenu.ts` и `CanvasMenu.tsx`.
- `backend` и `collab` не меняются: группа — обычная ячейка-контейнер документа, как таблица.
