# Design

## Context

`GET /api/boards` и `GET /api/boards/shared` уже отдают `openedAt` каждой доски пользователя: для своей — `seen_at` из
`board_reads`, для общей — `visited_at` из `board_visits`. По нему работает порядок «Недавно открытые».

## Decisions

- **Из готовых списков, без нового эндпоинта.** Страница уже загружает обе выборки; недавние — их объединение,
  отфильтрованное по `openedAt` и упорядоченное по нему. Доступ уже проверен выборками: доска, к которой у
  пользователя пропал доступ, пропадает и из недавних. Отдельный эндпоинт по `board_reads` повторил бы проверки доступа
  своих, общих и пространственных досок.
- **«Использованные» — открытые этим пользователем.** Не время изменения доски кем-то другим: иначе общая доска,
  которую правит команда, вытеснила бы доски, с которыми работает сам пользователь.
- **Шесть карточек** — две строки по три на широком экране и три по две на телефоне.
- **Без досок пространств.** Их списки грузятся на страницах пространств; на главной их нет.
- **Скрыт при фильтре.** При поиске, теге или папке пользователь ищет конкретное, и раздел только отодвигает
  результаты.

## Risks / Trade-offs

- Доска может быть и в недавних, и в списке ниже — это намеренно, как в других редакторах.
