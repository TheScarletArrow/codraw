# Proposal

## Why

Весь интерфейс CoDraw — по-русски, и строки записаны прямо в компонентах: библиотеки локализации нет. Англоязычной
команде доску не показать, а письма и сообщения уведомлений, «Что нового» и правовые страницы тоже только русские.
Задача — issue #62.

**До:** только русский интерфейс; строки в коде; новая русская строка ничем не проверяется.

**После:** русский и английский интерфейс с выбором по браузеру и переключателем «Язык» в меню пользователя; строки — в
словарях ru/en, а тесты ловят строку, которой нет в одном из словарей или которая записана в коде мимо словаря.

## What Changes

- Свой лёгкий модуль локализации фронтенда: словари `ru`/`en` рядом с модулями (`messages.ts`, `*.messages.ts`),
  типы TypeScript требуют в английском словаре те же ключи и те же функции подстановки, множественное число для обоих
  языков, даты и числа по языку интерфейса.
- Язык по умолчанию — первый из языков браузера, на котором говорит CoDraw, иначе русский; выбор «Язык» в меню
  пользователя запоминается в браузере (`localStorage`, `codraw.locale`) и перезагружает страницу на новом языке.
  `<html lang>` следует языку.
- Строки интерфейса фронтенда перенесены в словари и переведены: страницы, холст, палитра, панели, меню, уведомления в
  колокольчике, сообщения об ошибках backend (backend отвечает problem details по-английски, фронтенд говорит о них
  языком интерфейса), «… назад» и даты.
- «Что нового» двуязычное: каждая новинка каждой версии — на русском и английском.
- Правовые страницы на английском — перевод для удобства, при расхождении действует русская версия. Политика
  конфиденциальности называет выбор языка в браузере и язык учётной записи.
- Backend помнит язык интерфейса пользователя (`users.language`, `PUT /api/me/language`, `language` в `/api/me`):
  письма, подтверждение адреса и сообщения в чат приходят на нём. Новый гость получает имя на языке браузера («Guest
  N»), заглушка встроенной картинки и обратная ссылка в задаче GitHub — на языке запроса.
- Тесты: проверка словарей (ключ, которого нет в одном из языков; кириллица и пустые строки в английском) и сторож,
  который находит русскую строку в коде вне словаря. Тесты и e2e по-прежнему работают на русском (vitest — русский по
  умолчанию, Playwright — `locale: 'ru-RU'`).

## Capabilities

### New Capabilities

- `interface-language`: языки интерфейса, выбор по браузеру и переключатель, словари и их проверка, язык учётной записи.

### Modified Capabilities

- `release-notes`: новинки на языке интерфейса.
- `legal-pages`: английские версии и язык в политике конфиденциальности.
- `notification-delivery`: письма и сообщения в чат — на языке получателя.

## Impact

- `frontend`: новый `i18n/` (модуль, `LanguageMenu`, тесты словарей и сторож), словари во всех модулях с текстом,
  `api/http.ts` (`Accept-Language`), `api/auth.ts`, `Layout.tsx`, `releaseNotes/`, `legal/`; «Что нового» 0.38.0,
  README.
- `backend`: миграция V29/U29 (`users.language`), `Language`, `MeController`, `UserService`, `GuestLoginController`,
  `NotificationMessages`/`NotificationWords`, `NotificationDelivery`, `NotificationSettingsService`, `EmbedController`,
  `IssueLinkController`/`IssueLinkService`.
- `e2e`: `locale: 'ru-RU'` в конфигурациях Playwright, сценарий английского интерфейса.
- `collab` не меняется: он не показывает текстов людям.
- Вне рамок: языки кроме русского и английского; перевод содержимого досок пользователей; перевод текстов, которые
  импорт уже положил на доску; локализация сообщений об ошибках самого API (problem details остаются английскими —
  это контракт для клиентов).
