## ADDED Requirements

### Requirement: Вход заблокированного пользователя

Пользователь, которого заблокировал администратор, SHALL NOT входить: вход через GitHub или Google SHALL вести на
страницу входа с `?blocked`, где сказано «Учётная запись заблокирована администратором установки», а тестовый вход —
отвечать 403. Учётная запись при этом SHALL NOT меняться, кроме имени и аватара от провайдера.

#### Scenario: Вход через провайдера

- **WHEN** заблокированная Алиса входит через GitHub
- **THEN** сеанс не создаётся, и открывается страница входа с сообщением о блокировке

#### Scenario: Вход после разблокировки

- **WHEN** администратор разблокировал Алису, и она входит через GitHub
- **THEN** она входит, как раньше, со своими досками

### Requirement: Признак администратора в профиле

Профиль текущего пользователя `GET /api/me` SHALL содержать `admin`: `true` для администратора установки, `false` для
остальных, в том числе для гостей.

#### Scenario: Профиль администратора

- **WHEN** администратор запрашивает `/api/me`
- **THEN** ответ содержит `admin: true`
