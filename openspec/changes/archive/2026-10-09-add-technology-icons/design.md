# Design

## Context

Технология фигуры уже есть: свойство элемента `codrawTechnology` или `[Redis]`/`[Container: Go]` в подписи
(`elementProperties`). Картинки страницы рисует `ImageExport` maxGraph по состояниям ячеек.

## Decisions

### Значок — overlay, а не ячейка

Варианты: дочерняя ячейка-картинка, ключ `image` стиля, overlay maxGraph. Дочерняя ячейка меняла бы документ у всех,
попадала бы в выделение, копии и автораскладку и расходилась бы с технологией. `image` стиля рисует только фигура
`label`, а не цилиндр или облако. Overlay (`CellOverlay`) не меняет документ, масштабируется вместе с холстом, у
скрытой ячейки не рисуется, а `ImageExport.includeOverlays` рисует его в картинке. Значок вычисляется у каждого
участника из технологии, так что общий элемент на нескольких страницах показывает один логотип.

### Выбор значка — ключ вида ячейки

`codrawIcon` — ключ стиля ячейки, как цвет: копии, версии и `.drawio` переносят его без новых полей элемента. Поле
элемента (`ElementData`) разделялось бы общими элементами, но затронуло бы все места, где собираются свойства (подписи,
сравнение, слияние элементов), ради редкого случая: логотип по технологии и так общий. Выбор идёт через
`setElementProperties` и поэтому — шаг отмены, как другие свойства.

### Сопоставление технологии и логотипа

Ключ имени — как slug simple-icons (`+` → `plus`, `.` → `dot`, `#` → `sharp`, без диакритики): «Node.js» = `nodedotjs`.
Индекс: названия, затем другие имена (`aka`, `dup`, `loc`), затем названия без вендора («Apache Kafka» → «Kafka»), затем
короткий список синонимов (`k8s`, `postgres`, `java` → OpenJDK). Технология режется на перечисленные (`,`, `/`, ` и `),
без версий (`16`, `v3.2`, `LTS`), и пробуются первые слова от длинных к коротким: «Spring Boot WebFlux» → Spring Boot.

### Сборка набора

`index.mjs` simple-icons — 5 МБ с путями всех 3500 логотипов. Плагин Vite отдаёт виртуальный модуль каталога (slug,
название, цвет, имена — ~130 КБ, ~50 КБ gzip) и модули путей по первой букве slug (~100–400 КБ каждый); каталог
грузится, когда на странице есть технология или начат поиск, путь — когда нужен логотип его группы. Всё с адреса
приложения: CSP не меняется. `import.meta.glob` по 3500 файлам дал бы 3500 чанков и карту в основном коде.

### Облачные наборы

Условия значков AWS, Azure, Google Cloud, Yandex Cloud и Kubernetes разные, и использование в схемах — не то же, что
распространение значков в составе продукта. Задача требует проверить лицензию каждого набора до включения; эта
проверка — решение владельца проекта, поэтому эта версия наборы не включает, а облачные фигуры из файлов draw.io
сохраняет как есть, чтобы draw.io снова рисовал их после выгрузки. Наборы — следующим шагом, по одному, после проверки.

## Risks / Trade-offs

- Логотипы — товарные знаки; simple-icons публикует их под CC0 с оговоркой, README говорит о ней.
- Белые и очень светлые логотипы рисуются тёмно-серым: на белой подложке их иначе не видно.
