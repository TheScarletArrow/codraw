# Design

## Context

Подписи CoDraw — обычный текст: `graph.setHtmlLabels(false)`, потому что HTML от других участников позволил бы
внедрить скрипт. maxGraph рисует такую подпись элементами SVG `<text>`, по одному на строку из `\n`, и переносит
слова (`white-space: normal` в `foreignObject`) только у HTML-подписей: `CellRenderer` передаёт тексту
`graph.isWrapping(cell) && graph.isHtmlLabel(cell)`. Поэтому `whiteSpace: 'wrap'` в стиле фигур по умолчанию не
переносит подписи на доске, а только меняет поле правки подписи: его `CellEditor` переносит по `isWrapping`.
Автоширина (`autoWidth.ts`) уже меряет строки подписи шрифтом фигуры через canvas (`measureLabel`).

## Goals / Non-Goals

**Goals:**

- Перенос слов по ширине фигуры, включаемый для каждой фигуры, одинаковый у всех участников, в экспорте и во
  встраивании.
- Подписи остаются текстом без HTML.

**Non-Goals:**

- Рост высоты фигуры под перенесённый текст и обрезка текста, который не поместился.
- Перенос подписей связей, таблиц и полей таблиц.
- Переносы внутри слов по слогам и выравнивание по ширине.

## Decisions

### Строки считает CoDraw, а не браузер

- `wrapLabel(text, style, width)` в `autoWidth.ts`: каждую строку подписи жадно набирает из слов, пока строка с
  шрифтом подписи (`measureLabel`) не шире `width`; слово шире `width` разбивается по буквам; пробелы на месте
  переноса убираются. Где браузер не меряет текст (jsdom), ширины нулевые, и подпись не переносится.
- Подключается переопределением `graph.getLabel` рядом с полями таблиц: у фигуры с переносом подпись для показа —
  строки через `\n`. `getLabel` вызывается при каждой перерисовке ячейки, поэтому строки пересчитываются после
  изменения ширины, подписи и стиля, и тем же кодом их рисуют экспорт SVG/PNG (`renderSvg`) и встраивание.
  `getEditingValue` и значение ячейки не меняются: правится и синхронизируется исходный текст.
- Ширина строки — ширина фигуры за вычетом отступов подписи и полей, которые добавляет `fittedWidth`. Так фигура,
  подогнанная автошириной, после включения переноса не перестраивает подпись.
- Меряется в единицах модели при размере шрифта без масштаба, поэтому строки не зависят от масштаба доски.
- Альтернатива — HTML-подписи для фигур с переносом с экранированным текстом и `foreignObject`. Отклонено: любой
  путь, где значение ячейки не экранировано, открывает внедрение скриптов; `foreignObject` иначе ведёт себя в
  экспорте PNG через canvas; поле правки становится `contentEditable` с HTML.

### Ключ и значение по умолчанию

- Перенос — ключ `whiteSpace: 'wrap'` в стиле ячейки, выключенный — без ключа, как в draw.io; `parseStyle` и экспорт
  уже переносят ключ. Из стиля вершин по умолчанию ключ убирается: фигуры без ключа не переносят и при правке подписи.
- Действует перенос у фигуры, которая допускает автоширину (`allowsAutoWidthCell`), не таблицы и без автоширины. У
  фигуры из файла с `autosize=1` и `whiteSpace=wrap` побеждает автоширина: иначе ширина подгонялась бы под
  перенесённые строки и сжималась.

### Команда и панель

- `SelectionText.textWrap: boolean | null` — `null`, когда среди выделенных нет фигур, которые допускают перенос.
- `setTextWrap(enabled)` в одном `batchUpdate` ставит или убирает `whiteSpace` у таких фигур и при включении
  убирает `autosize`; `setAutoWidth(true)` убирает `whiteSpace`. Обе в списке меняющих команд (режим «Просмотр»).
- Кнопка «Перенос» с иконкой `WrapText` — рядом с «Автошириной», тем же видом.

## Risks / Trade-offs

- [Ширина строк canvas и SVG `<text>` расходится на доли пикселя, а при масштабе — из-за хинтинга] → поля
  `fittedWidth` оставляют запас по краям фигуры.
- [Измерение слов на каждой перерисовке фигуры с переносом] → только у фигур с переносом; `measureText` быстрый.
- [Доски с фигурами из файлов draw.io с `whiteSpace=wrap` начнут переносить их подписи] → так их показывает draw.io;
  перенос выключается кнопкой.
