# Proposal

## Why

Длинная подпись фигуры рисуется одной строкой и вылезает за её края: перенести слова можно только вручную, через
Enter, и после каждого изменения ширины — заново. «Автоширина» растит фигуру под строку, но схеме часто нужна
фигура постоянной ширины с подписью в несколько строк. Стиль фигур по умолчанию уже содержит `whiteSpace: 'wrap'`,
но переносит текст maxGraph только у HTML-подписей, а их CoDraw выключает, так что ключ не работает.

## What Changes

- Кнопка «Перенос» на панели инструментов в блоке текста, рядом с «Автошириной»: включает и выключает у выделенных
  фигур перенос слов по ширине фигуры, одним шагом отмены. По умолчанию перенос выключен.
- Подпись фигуры с переносом разбивается на строки по ширине фигуры за вычетом отступов; слово длиннее строки
  разбивается по буквам; высота фигуры не меняется. Строки пересчитываются при изменении ширины, подписи, размера,
  начертания и шрифта текста — на доске, в экспорте SVG и PNG и во встраивании.
- «Перенос» и «Автоширина» исключают друг друга: включение одного выключает другое в том же шаге отмены.
- Перенос хранится ключом draw.io `whiteSpace=wrap` и переносится через `.drawio`; фигуры из файлов draw.io с этим
  ключом переносят текст, как в draw.io.
- Из стиля фигур по умолчанию убирается неработающий `whiteSpace: 'wrap'`: фигуры без ключа не переносят текст и
  при правке подписи.

## Capabilities

### New Capabilities

- нет

### Modified Capabilities

- `text-format`: перенос слов по ширине фигуры.

## Impact

- `frontend`: `diagram/autoWidth.ts` (раскладка подписи по строкам), `diagram/editor.ts` (подписи с переносом,
  состояние и команда переноса, взаимоисключение с автошириной, стиль по умолчанию), `diagram/EditorToolbar.tsx`.
- `backend`, `collab` не меняются; новых зависимостей нет.
