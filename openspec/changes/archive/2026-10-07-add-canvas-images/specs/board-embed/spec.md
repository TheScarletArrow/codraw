# Spec Delta

## ADDED Requirements

### Requirement: Изображения в живой картинке

Живая картинка SHALL показывать фигуры-изображения: браузер SHALL вкладывать их в публикуемый SVG, уменьшенными не
больше чем до вдвое большего размера фигуры. Если `backend` отклонил такую картинку по пределу размера, браузер SHALL
публиковать SVG без изображений.

#### Scenario: Скриншот на встроенной странице

- **WHEN** участник вставил скриншот на встроенную страницу
- **THEN** через несколько секунд ссылка живой картинки отдаёт SVG со скриншотом внутри
