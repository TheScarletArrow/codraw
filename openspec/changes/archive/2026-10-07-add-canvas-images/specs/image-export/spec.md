# Spec Delta

## ADDED Requirements

### Requirement: Изображения в экспорте

PNG, SVG, PDF и «Копировать PNG» SHALL содержать картинки фигур-изображений внутри файла, чтобы файл показывал их без
доступа к доске и без сети; схема внутри SVG SHALL нести их так же, как экспорт в `.drawio`. Картинка, которую браузер
не смог скачать, SHALL быть в файле заглушкой.

#### Scenario: PNG с картинкой

- **WHEN** на странице фигура-изображение с красным логотипом, и участник сохраняет PNG
- **THEN** на PNG виден красный логотип

#### Scenario: SVG с картинкой

- **WHEN** участник сохраняет SVG страницы с фигурой-изображением
- **THEN** в SVG у `<image>` строка `data:image/…;base64,`, а ссылок на `/api/` нет
