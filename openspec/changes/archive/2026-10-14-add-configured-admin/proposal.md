## Why

Чтобы стать администратором установки с паролем, сейчас нужно включить вход по паролю, зарегистрироваться, вписать
свой логин в `CODRAW_ADMINS` и перезапустить `backend`. Установке без GitHub, Google и корпоративного провайдера нужен
администратор с первого запуска: оператор задаёт логин и пароль в `.env.prod` — и сразу входит.

## What Changes

- Настройки `codraw.admin.login` и `codraw.admin.password` (`CODRAW_ADMIN_LOGIN`, `CODRAW_ADMIN_PASSWORD`). Задаются
  вместе; логин и пароль подчиняются правилам входа по паролю; иначе `backend` не запускается и называет ошибку.
- При каждом старте `backend` создаёт учётную запись с этим логином, если её нет, и приводит её пароль к паролю из
  настроек; если пароль изменился, все сеансы этой учётной записи завершаются. Блокировка с неё снимается.
- Эта учётная запись — администратор установки, как `password:<логин>` в `CODRAW_ADMINS`; её логин не
  зарегистрировать.
- С заданным администратором страница входа показывает форму входа по паролю, даже если `CODRAW_PASSWORDS_ENABLED` не
  включён; регистрация при этом остаётся выключенной, пока её не включат.
- Пароль администратора из настроек меняется только настройкой: раздел «Пароль» на странице «Учётная запись» говорит
  об этом вместо формы, `PUT /api/me/password` отвечает 403.
- `docker-compose.prod.yml`, `.env.prod.example`, `docs/deploy.md`, README.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `admin-moderation`: администратор с логином и паролем из настроек.
- `password-sign-in`: вход по паролю для администратора из настроек без общего входа по паролю; пароль такого
  администратора не меняется в интерфейсе.

## Impact

- `backend`: `AdminProperties` (`login`, `password`, проверка при старте, без пароля в `toString`), учётная запись
  при старте в `PasswordService`, предложение входа по паролю, `/api/me` (`passwordFromSettings`), отказ смены пароля,
  тесты.
- `frontend`: раздел «Пароль» для администратора из настроек.
- `docker-compose.prod.yml`, `.env.prod.example`, `docs/deploy.md`, README.
