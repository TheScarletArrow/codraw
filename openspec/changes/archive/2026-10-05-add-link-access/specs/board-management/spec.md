# Spec Delta

## MODIFIED Requirements

### Requirement: Получение доски

Система SHALL возвращать по запросу `GET /api/boards/{id}` идентификатор, название, время создания
и время последнего изменения доски, её режим доступа по ссылке `linkAccess`, её владельца — идентификатор, имя
и аватар — и роль текущего пользователя на доске: `owner` для владельца, `editor` для остальных при режиме `edit`
и `viewer` — при режиме `view`.

#### Scenario: Доска существует

- **WHEN** клиент запрашивает `GET /api/boards/{id}` существующей доски
- **THEN** ответ имеет статус 200 и содержит `id`, `title`, `createdAt`, `updatedAt`, `linkAccess` и `owner`
  с полями `id`, `name` и `avatarUrl`

#### Scenario: Роль владельца и участника по ссылке

- **WHEN** владелец доски A и пользователь B, открывший её по ссылке, запрашивают `GET /api/boards/{id}`
- **THEN** A получает `role` = `owner`, а B — `role` = `editor`, и оба получают одного и того же владельца

#### Scenario: Роль участника доски для просмотра

- **WHEN** пользователь B запрашивает `GET /api/boards/{id}` доски пользователя A с режимом `view`
- **THEN** B получает `role` = `viewer`

#### Scenario: Доска не существует

- **WHEN** клиент запрашивает доску с несуществующим идентификатором или с идентификатором не
  в формате UUID
- **THEN** ответ имеет статус 404

### Requirement: Доски, открытые по ссылке

Система SHALL запоминать доски других пользователей, которые пользователь получил запросом
`GET /api/boards/{id}`, и возвращать их по запросу `GET /api/boards/shared`: не больше 50 досок, недавно открытые
первыми, с владельцем, ролью и временем последнего открытия каждой. Свои доски в этот список не попадают,
а удалённая доска и доска, доступ к которой по ссылке закрыт, пропадают из него.

#### Scenario: Чужие доски в списке открытых

- **WHEN** пользователь B открыл по ссылке доску X пользователя A, а затем доску Y пользователя A
- **THEN** `GET /api/boards/shared` для B возвращает Y раньше X, у обеих `owner.name` — имя A, а
  `GET /api/boards` для B этих досок не содержит

#### Scenario: Повторное открытие

- **WHEN** B открыл доски X и Y, а затем снова открыл X
- **THEN** `GET /api/boards/shared` для B возвращает X раньше Y

#### Scenario: Свои доски не попадают в список открытых

- **WHEN** владелец открывает свою доску
- **THEN** её нет в ответе `GET /api/boards/shared` для владельца

#### Scenario: Удалённая доска

- **WHEN** B открыл доску X, а её владелец удалил X
- **THEN** X нет в ответе `GET /api/boards/shared` для B

#### Scenario: Доступ по ссылке закрыт

- **WHEN** B открыл доску X, а её владелец сменил режим доступа на `none`
- **THEN** X нет в ответе `GET /api/boards/shared` для B; после возврата режима `view` X снова в списке
  с `role` = `viewer`

#### Scenario: Больше 50 открытых досок

- **WHEN** B открыл 51 чужую доску
- **THEN** `GET /api/boards/shared` возвращает 50 досок, открытых последними
