# Spec Delta

## MODIFIED Requirements

### Requirement: Список досок

Система SHALL возвращать по запросу `GET /api/boards` список досок текущего пользователя,
отсортированный по времени последнего изменения, начиная с самых свежих. У каждой доски SHALL быть, кроме полей доски,
раскладка текущего пользователя: `tags` — его теги доски, `folderId` — его папка доски или `null`, и `openedAt` —
когда он последний раз был на доске, или `null`, пока не был.

#### Scenario: Несколько досок

- **WHEN** у пользователя есть доски A и B, и B изменялась позже A
- **THEN** `GET /api/boards` возвращает B раньше A

#### Scenario: Досок нет

- **WHEN** пользователь ещё не создал ни одной доски
- **THEN** `GET /api/boards` возвращает статус 200 и пустой список

#### Scenario: Чужие доски не попадают в список

- **WHEN** у пользователя A есть доска, а пользователь B запрашивает `GET /api/boards`
- **THEN** доски пользователя A нет в ответе

#### Scenario: Время открытия своей доски

- **WHEN** владелец открыл свою доску X и не открывал доску Y
- **THEN** `GET /api/boards` содержит у X `openedAt` — время, когда он был на ней, а у Y — `null`

#### Scenario: Теги и папка

- **WHEN** пользователь дал доске теги «Бэкенд» и «Архив» и положил её в папку «Работа»
- **THEN** `GET /api/boards` содержит у доски эти `tags` и `folderId` папки «Работа», а у других досок — пустые `tags`
  и `folderId` = `null`

### Requirement: Общие доски

Система SHALL запоминать доски других пользователей, которые пользователь получил запросом
`GET /api/boards/{id}`, и возвращать по запросу `GET /api/boards/shared` их и доски, где он участник, даже не
открытые: не больше 50, недавно открытые или ставшие общими первыми, с владельцем, ролью, временем последнего открытия
(`null`, пока не открывали) и раскладкой пользователя — его тегами `tags` и папкой `folderId`. Свои доски в список не
попадают, удалённая пропадает, а доска с закрытой ссылкой остаётся, только если пользователь её участник.

#### Scenario: Чужие доски в списке открытых

- **WHEN** пользователь B открыл по ссылке доску X пользователя A, а затем доску Y пользователя A
- **THEN** `GET /api/boards/shared` для B возвращает Y раньше X, у обеих `owner.name` — имя A, а
  `GET /api/boards` для B этих досок не содержит

#### Scenario: Повторное открытие

- **WHEN** B открыл доски X и Y, а затем снова открыл X
- **THEN** `GET /api/boards/shared` для B возвращает X раньше Y

#### Scenario: Свои доски не попадают в список открытых

- **WHEN** владелец открывает свою доску
- **THEN** её нет в ответе `GET /api/boards/shared` для владельца

#### Scenario: Удалённая доска

- **WHEN** B открыл доску X, а её владелец удалил X
- **THEN** X нет в ответе `GET /api/boards/shared` для B

#### Scenario: Доступ по ссылке закрыт

- **WHEN** B открыл доску X, а её владелец сменил режим доступа на `none`
- **THEN** X нет в ответе `GET /api/boards/shared` для B; после возврата режима `view` X снова в списке
  с `role` = `viewer`

#### Scenario: Больше 50 открытых досок

- **WHEN** B открыл 51 чужую доску
- **THEN** `GET /api/boards/shared` возвращает 50 досок, открытых последними

#### Scenario: Доска участника до открытия

- **WHEN** владелец доски X добавил B участником с ролью `viewer`, и B ещё не открывал X
- **THEN** `GET /api/boards/shared` для B содержит X с `role` = `viewer` и `openedAt` = `null`

#### Scenario: Участник при закрытой ссылке

- **WHEN** B — участник доски X с ролью `editor`, и владелец сменил режим доступа на `none`
- **THEN** X остаётся в ответе `GET /api/boards/shared` для B с `role` = `editor`

#### Scenario: Раскладка общей доски

- **WHEN** B дал общей доске X тег «Платежи» и положил её в свою папку «Чужие»
- **THEN** `GET /api/boards/shared` для B содержит у X `tags` = `["Платежи"]` и `folderId` папки «Чужие»

### Requirement: Управление досками на главной странице

Главная страница SHALL показывать у каждой своей доски меню с пунктами «Переименовать», «Теги», «Переместить в папку» и
«Удалить», а под списком своих досок — раздел «Общие со мной» с досками из `GET /api/boards/shared`, именем владельца и
ролью пользователя («редактирование» или «просмотр») у каждой и меню доски только с пунктами «Теги» и «Переместить в
папку»; раздел «Начать с шаблона» SHALL идти после раздела «Общие со мной». Удаление SHALL требовать подтверждения.

#### Scenario: Переименование из списка

- **WHEN** пользователь выбирает «Переименовать» в меню своей доски, вводит новое название и нажимает Enter
- **THEN** доска показывается в списке с новым названием; Escape вместо Enter оставляет прежнее название

#### Scenario: Удаление из списка

- **WHEN** пользователь выбирает «Удалить» в меню своей доски
- **THEN** страница просит подтвердить удаление доски с её названием; после подтверждения доска пропадает
  из списка, а отказ оставляет её

#### Scenario: Раздел «Открытые по ссылке»

- **WHEN** пользователь B открывал по ссылке доску пользователя A
- **THEN** главная страница B показывает эту доску в разделе «Общие со мной» с именем A и ролью B, а в меню доски у B
  есть «Теги» и «Переместить в папку» и нет переименования и удаления
