# Proposal

## Why

Схемы живут не только на доске: их вставляют в README, Confluence, Notion, задачи и документацию. Сейчас для этого
выгружают PNG, и через неделю картинка в документе уже не совпадает со схемой. В draw.io «живая» картинка есть только
через интеграции с Confluence и Google Drive. Ссылка на картинку, которая всегда показывает текущую схему, делает доску
CoDraw источником правды для документации: поправили схему — README обновился сам.

## What Changes

- Владелец включает в окне «Поделиться» «Живая картинка» и выбирает страницу. Появляется постоянная ссылка
  `/api/embeds/{ключ}.svg` и готовая строка Markdown `![Название](ссылка)`; выключение удаляет картинку, а новое
  включение даёт новый ключ.
- Картинку рисуют браузеры участников, которые правят доску: после их правок страницы (не чаще раза в несколько
  секунд) страница рисуется в SVG, как при экспорте, и отправляется в `backend`. Сервер ничего не рисует.
- `backend` хранит последнюю картинку доски и отдаёт её по ключу без входа, с `Content-Type: image/svg+xml`,
  короткой проверкой свежести (`ETag`, `Cache-Control: max-age=60`) и политикой `sandbox`, а до первой картинки —
  заглушку «Схема ещё не нарисована». Присланный SVG очищается по белому списку элементов и атрибутов: без скриптов,
  обработчиков событий, внешних ссылок и стилей с внешними адресами.
- Предел размера картинки `codraw.limits.embed-size` (2 МБ).
- Политика конфиденциальности и условия говорят, что включённая картинка доступна любому, у кого есть ссылка, даже
  если доступ к доске по ссылке закрыт.

## Capabilities

### New Capabilities

- `board-embed`: живая картинка страницы доски по постоянной ссылке для документации.

### Modified Capabilities

- `legal-pages`: политика говорит о публичной картинке доски.

## Impact

- `backend`: миграция (`board_embeds`), пакет `embed` (сервис, контроллер, очистка SVG), открытый `GET
  /api/embeds/{ключ}.svg`, предел размера, тесты.
- `frontend`: раздел «Живая картинка» окна «Поделиться», публикация картинки из браузеров правящих участников
  (рисование страницы вне холста), API.
- nginx не меняется: картинка идёт по `/api/`.
