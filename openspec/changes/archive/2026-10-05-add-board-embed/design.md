# Design

## Context

Экспорт в SVG рисует страницу в браузере (`renderSvg`: `ImageExport` + `SvgCanvas2D` maxGraph) из вида редактора.
У `backend` нет ни maxGraph, ни браузера, а документ доски для него — двоичное состояние Yjs. nginx проксирует `/api/`
в `backend` и не добавляет туда заголовков безопасности приложения. Доступ к доске — роль по режиму ссылки;
правят владелец и участники с ролью `editor`.

## Goals / Non-Goals

**Goals:**

- Постоянный адрес картинки страницы, которая обновляется вслед за правками, для `<img>` и Markdown.
- Безопасно отдавать картинку, присланную браузером, с того же домена, что и приложение.

**Non-Goals:**

- PNG, выбор масштаба и темы, встраивание интерактивной доски (`<iframe>`).
- Несколько картинок на доску (одна страница), статистика просмотров.
- Рисование на сервере (headless-браузер) — тяжёлая зависимость; возможно позже для досок без участников онлайн.

## Decisions

### Картинку рисуют браузеры правящих участников

- После локальной правки ячеек встроенной страницы (транзакция Yjs не от синхронизации) браузер ждёт 3 с тишины
  и не чаще раза в 10 с рисует страницу вне холста: скрытый редактор этой страницы только для чтения → `exportSvg`
  → `PUT /api/boards/{id}/embed/image`. Включение и смена страницы владельцем публикуют сразу.
- Чужие правки публикует их автор, поэтому картинка — состояние после последней правки любого правящего участника.
  Участник в режиме «Просмотр» не публикует: он не правит.
- Альтернатива — рисование на сервере headless Chromium. Отклонена: сотни мегабайт в образе ради одной функции.

### Хранение и API

- Таблица `board_embeds`: доска (ключ и `ON DELETE CASCADE`), ключ картинки (случайные 128 бит в base64url,
  уникальный), страница, SVG (`bytea`, `NULL` до первой картинки), время картинки и создания.
- `GET /api/boards/{id}/embed` — любой участник (404 — выключено); `PUT` с `{pageId}` и `DELETE` — только владелец;
  `PUT /api/boards/{id}/embed/image?pageId=…` — владелец и `editor`, только для текущей страницы картинки (иначе 409),
  тело — `image/svg+xml` до `codraw.limits.embed-size`.
- `GET /api/embeds/{ключ}.svg` — без входа: SVG или заглушка, `ETag` по времени картинки, `Cache-Control: public,
  max-age=60`, `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; img-src data:; sandbox`,
  `X-Content-Type-Options: nosniff`, `Cross-Origin-Resource-Policy: cross-origin` — чтобы встраивали другие сайты.
- Ключ — в адресе, а не id доски: выключение и новое включение отзывают старые ссылки; по ключу нельзя открыть доску.

### Очистка SVG

- Разбор XML без DOCTYPE и внешних сущностей (`disallow-doctype-decl`), обход дерева: остаются элементы SVG из белого
  списка (фигуры, текст, группы, градиенты, маркеры, `clipPath`, `switch`, `foreignObject` для подписей HTML с `div`,
  `span`, `br`, `b`, `i`, `u`, `font` XHTML) и их атрибуты из белого списка; `on*`, `<script>`, `<style>`, ссылки, кроме
  `#id` и `data:image/(png|jpeg|gif|webp)`, и `style` с `url(` не на `#`, `expression(`, `@import`, `javascript:` —
  удаляются. Даже если очистка что-то пропустит, `sandbox` не даст выполнить скрипт при открытии адреса напрямую, а в
  `<img>` SVG скрипты не выполняет.

### Интерфейс

- Раздел «Живая картинка» в окне «Поделиться»: у владельца — переключатель и выбор страницы; когда включено — поле
  со ссылкой и кнопки «Копировать ссылку» и «Копировать Markdown». Участники видят ссылку, если картинка включена.
- Публикатор — хук страницы доски: знает встроенную страницу из `GET …/embed` (обновляется сообщением
  `board-changed`) и роль участника.

## Risks / Trade-offs

- [Картинка отстаёт, если правили только через API или правки пришли от участника с закрытой вкладкой до отправки]
  → следующая правка любого правящего участника обновит её; кнопки «Обновить сейчас» нет, но включение заново
  публикует сразу.
- [Нагрузка от частых правок] → не чаще раза в 10 с на браузер, размер — до 2 МБ, предел числа досок ограничивает
  число картинок.
- [Утечка: картинка публична] → включает только владелец, явно, с предупреждением; выключение удаляет картинку.
