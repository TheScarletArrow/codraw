## MODIFIED Requirements

### Requirement: Администраторы из конфигурации

Администраторов установки SHALL задавать только конфигурация `backend` (`CODRAW_ADMINS`): список учётных записей вида
`<провайдер>:<id у провайдера>` через запятую (`github`, `google`, `yandex`, `vk`), например `github:583231`, а
пользователей корпоративного провайдера — `oidc:<issuer>:<sub>`. Ни API, ни интерфейс SHALL NOT назначать и снимать
администраторов. Гость администратором не бывает: запись с провайдером `guest` или неизвестным провайдером SHALL NOT
давать `backend` запуститься.

#### Scenario: Администратор по конфигурации

- **WHEN** в `CODRAW_ADMINS` есть `github:42`, и входит пользователь GitHub с id `42`
- **THEN** он администратор: `/api/me` отвечает `admin: true`, API администрирования ему доступно

#### Scenario: Администратор VK ID

- **WHEN** в `CODRAW_ADMINS` есть `vk:1234567`, и через VK ID входит пользователь с `user_id` `1234567`
- **THEN** он администратор

#### Scenario: Администратор корпоративного провайдера

- **WHEN** в `CODRAW_ADMINS` есть `oidc:https://sso.example.com/realms/acme:a1`, и через этого провайдера входит
  пользователь с `sub` = `a1`
- **THEN** он администратор

#### Scenario: Остальные не администраторы

- **WHEN** входит пользователь, которого нет в `CODRAW_ADMINS`, или гость
- **THEN** `/api/me` отвечает `admin: false`

#### Scenario: Неверная запись

- **WHEN** в `CODRAW_ADMINS` есть `guest:…`, запись без двоеточия или `oidc:` без issuer или `sub`
- **THEN** `backend` не запускается и называет неверную запись
