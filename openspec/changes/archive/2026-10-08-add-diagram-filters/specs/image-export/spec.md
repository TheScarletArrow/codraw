# Spec Delta

## ADDED Requirements

### Requirement: Только видимое

Пока на странице включён фильтр, окно экспорта SHALL предлагать флажок «Только видимое». С ним PNG, SVG, PDF текущей
страницы и всех страниц и копия PNG SHALL содержать только то, что подходит под фильтр, без приглушённого; схема внутри
SVG — тоже. Без флажка изображение SHALL содержать всю страницу без приглушения, как без фильтра.

#### Scenario: Срез в PNG

- **WHEN** выбран владелец «Платежи», и участник отмечает «Только видимое» и сохраняет PNG
- **THEN** в изображении только элементы «Платежей» и связи между ними, и оно уже изображения всей страницы

#### Scenario: Без флажка

- **WHEN** выбран владелец «Платежи», и участник сохраняет SVG без «Только видимое»
- **THEN** в SVG все элементы страницы непрозрачными
