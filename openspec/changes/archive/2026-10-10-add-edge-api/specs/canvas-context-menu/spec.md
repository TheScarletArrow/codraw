# Spec Delta

## ADDED Requirements

### Requirement: Описание API из меню

Меню правого щелчка одной связи SHALL содержать «Описание API…» после «Ссылка…»; пункт SHALL открывать панель описания
этой связи в режиме правки. У закреплённой связи пункт SHALL быть неактивным, участнику в режиме «Просмотр» пункт SHALL
не показываться. Меню фигуры, таблицы, группы, поля, индекса, нескольких элементов и пустого холста пункта SHALL не
содержать.

#### Scenario: Описать связь

- **WHEN** участник щёлкает правой кнопкой по связи без описания и выбирает «Описание API…»
- **THEN** справа открывается форма описания этой связи

#### Scenario: Только просмотр

- **WHEN** участник в режиме «Просмотр» щёлкает правой кнопкой по связи
- **THEN** пункта «Описание API…» в меню нет
