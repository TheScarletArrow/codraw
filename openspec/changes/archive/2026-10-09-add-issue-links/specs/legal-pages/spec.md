# Spec Delta

## ADDED Requirements

### Requirement: Задачи GitHub в политике конфиденциальности

Если установка привязывает задачи GitHub (`issues` в `/api/legal`), политика конфиденциальности SHALL называть токен
GitHub с учётной записью, который не показывается никому, и привязанные задачи с тем, кто их привязал; сроки — токен до
отключения или замены, не дольше учётной записи, привязка — до отвязки, не дольше доски и ветки; получателей — GitHub по
действиям пользователя и участников доски, которые видят номер, название и статус задачи. Без задач политика SHALL о
них молчать.

#### Scenario: Задачи включены

- **WHEN** установка привязывает задачи GitHub, и посетитель открывает `/privacy`
- **THEN** политика называет токен GitHub, привязанные задачи, срок их хранения и то, что их видят участники доски
