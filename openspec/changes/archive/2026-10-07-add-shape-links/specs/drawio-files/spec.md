# Spec Delta

## ADDED Requirements

### Requirement: Ссылки элементов в файлах draw.io

Экспорт в `.drawio` SHALL записывать ссылку элемента атрибутом `link` элемента `<UserObject>`, в который обёрнута его
ячейка, а если у элемента есть и свои свойства — элемента `<object>` с ними. Ссылка на страницу доски SHALL
записываться как `data:page/id,<id>`, где `<id>` — id диаграммы этой страницы в файле, ссылка на доску — адресом
доски. Импорт файла, файла `.drawio.svg` и вставка фрагмента draw.io из буфера обмена SHALL делать атрибут `link`
`<UserObject>` и `<object>` ссылкой элемента. Если импорт дал странице файла другой id, ссылки на эту страницу из
импортированных элементов SHALL вести на неё же. Небезопасный `link` (см. «Безопасные адреса») SHALL отбрасываться при
импорте и не записываться при экспорте. Копирование элементов со ссылками в буфер обмена SHALL записывать их ссылки так
же, как экспорт.

#### Scenario: Экспорт ссылки на страницу

- **WHEN** у фигуры ссылка на страницу «Контейнеры», и доску экспортируют в `.drawio`
- **THEN** ячейка фигуры в файле обёрнута в `<UserObject>` с `link="data:page/id,<id страницы «Контейнеры»>"`, а у
  диаграммы «Контейнеры» тот же id

#### Scenario: Импорт ссылки на страницу

- **WHEN** экспортированный файл со ссылкой на страницу импортируют в новую доску
- **THEN** у фигуры значок ссылки, и `Ctrl+щелчок` по ней открывает страницу «Контейнеры» новой доски

#### Scenario: Id страницы занят

- **WHEN** в файле две страницы, первая с id `page-1`, и фигура второй страницы ссылается на первую, а файл
  импортируют в доску, где страница `page-1` уже есть
- **THEN** первая страница файла получает новый id, и ссылка фигуры ведёт на неё

#### Scenario: Небезопасная ссылка в файле

- **WHEN** в импортируемом файле у фигуры `link="javascript:alert(1)"`
- **THEN** фигура импортируется без ссылки
