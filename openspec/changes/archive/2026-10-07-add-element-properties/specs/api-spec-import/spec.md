# Spec Delta

## ADDED Requirements

### Requirement: Свойства импортированных элементов

Фигура сервиса SHALL иметь свойства элемента: имя — название API или приложения, тип «Сервис», описание — первый абзац
`info.description` документа (не длиннее 500 символов). Сервис AsyncAPI и его топики SHALL иметь технологией протоколы
серверов документа (`kafka` — Kafka, `amqp` — AMQP, `mqtt` — MQTT, иначе как в документе), топик — имя-адрес и тип
«Топик событий»; связи сервиса с топиками SHALL быть асинхронными с той же технологией. Подписи фигур и связей свойства
SHALL не менять.

#### Scenario: Описание сервиса

- **WHEN** импортирован OpenAPI «Orders API» с `info.description` «Заказы магазина.»
- **THEN** у сервиса имя «Orders API», тип «Сервис» и описание «Заказы магазина.»

#### Scenario: Протокол Kafka

- **WHEN** импортирован AsyncAPI с сервером `protocol: kafka`, который отправляет в канал `orders.created`
- **THEN** у топика «orders.created» технология `Kafka`, а связь от сервиса к нему асинхронная с технологией `Kafka`
