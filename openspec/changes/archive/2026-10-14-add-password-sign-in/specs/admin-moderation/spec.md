## MODIFIED Requirements

### Requirement: Администраторы из конфигурации

Администраторов установки SHALL задавать только конфигурация `backend` (`CODRAW_ADMINS`): список учётных записей вида
`<провайдер>:<id у провайдера>` через запятую, например `github:583231,google:1098…`, пользователей корпоративного
провайдера — `oidc:<issuer>:<sub>`, а пользователей с паролем — `password:<логин>` без учёта регистра. Ни API, ни
интерфейс SHALL NOT назначать и снимать администраторов. Гость администратором не бывает: запись с провайдером
`guest` или неизвестным провайдером SHALL NOT давать `backend` запуститься. Логин из `CODRAW_ADMINS` SHALL NOT
регистрироваться.

#### Scenario: Администратор по конфигурации

- **WHEN** в `CODRAW_ADMINS` есть `github:42`, и входит пользователь GitHub с id `42`
- **THEN** он администратор: `/api/me` отвечает `admin: true`, API администрирования ему доступно

#### Scenario: Администратор корпоративного провайдера

- **WHEN** в `CODRAW_ADMINS` есть `oidc:https://sso.example.com/realms/acme:a1`, и через этого провайдера входит
  пользователь с `sub` = `a1`
- **THEN** он администратор

#### Scenario: Администратор с паролем

- **WHEN** пользователь зарегистрировал логин `Admin`, в `CODRAW_ADMINS` вписали `password:admin`, и он входит по
  паролю
- **THEN** он администратор

#### Scenario: Логин администратора не занять

- **WHEN** в `CODRAW_ADMINS` есть `password:root`, а логин `root` ещё никто не зарегистрировал, и посетитель
  регистрирует `Root`
- **THEN** ответ имеет статус 403, учётная запись не создаётся, а форма сообщает, что логин зарезервирован

#### Scenario: Остальные не администраторы

- **WHEN** входит пользователь, которого нет в `CODRAW_ADMINS`, или гость
- **THEN** `/api/me` отвечает `admin: false`

#### Scenario: Неверная запись

- **WHEN** в `CODRAW_ADMINS` есть `guest:…`, запись без двоеточия или `oidc:` без issuer или `sub`
- **THEN** `backend` не запускается и называет неверную запись
