# Proposal

## Why

Индексы — часть схемы, по которой читают производительность запросов: какие выборки быстрые, где составной индекс,
где частичный. Сейчас на доске их не видно: импорт SQL пропускает `CREATE INDEX`, составной `UNIQUE (a, b)` теряется,
поставить индекс руками нельзя, а выгрузка SQL выдаёт схему без индексов.

## What Changes

- У таблицы появляется блок «Индексы» под полями: отделён линией с подписью, строка — индекс: значок, имя, столбцы
  или выражения в скобках, `UNIQUE`, метод (`USING gin`) и условие (`WHERE …`). Составные индексы — одной строкой.
- Поле таблицы, которое входит в индекс, показывает значок индекса после значков ключей.
- «Добавить индекс» на панели таблицы и в её контекстном меню добавляет строку и начинает правку имени. Выделенный
  индекс показывает на панели и рядом со строкой «Столбцы» и `UNIQUE`; имя правится в строке, как имя поля, а весь
  текст индекса можно ввести целиком: `users_org_idx (org_id, created_at) WHERE deleted_at IS NULL`.
- Импорт SQL разбирает `CREATE [UNIQUE] INDEX`, `DROP INDEX`, `ALTER INDEX … RENAME TO`, `INDEX`/`KEY` и составной
  `UNIQUE (a, b)` внутри `CREATE TABLE`; переименование и удаление столбцов меняют индексы с ними. Сводка импорта
  называет число индексов, а `CREATE INDEX` больше не считается пропущенным оператором.
- Выгрузка SQL дописывает `CREATE [UNIQUE] INDEX … ON …` для индексов таблиц страницы; в Mermaid индексов нет, и
  строки индексов не становятся столбцами.
- Строки индексов хранятся дочерними ячейками таблицы с ключом стиля и переносятся через `.drawio`, буфер обмена,
  шаблоны и версии.

## Capabilities

### New Capabilities

- `table-indexes`: блок индексов таблицы, значок индекса у поля, добавление и правка индексов.

### Modified Capabilities

- `sql-schema`: импорт понимает операторы индексов и составные `UNIQUE`, сводка называет индексы; выгрузка SQL
  создаёт индексы.
- `diagram-shapes`: в «Отображение поля таблицы» добавляется значок индекса.

## Impact

- `frontend`: новый `sql/tableIndex.ts` (текст строки индекса), `sql/parseSql.ts` (индексы схемы),
  `sql/erDiagram.ts` (строки индексов при импорте, `CREATE INDEX` в выгрузке, без индексов в столбцах),
  `sql/SqlMenu.tsx` (сводка), `diagram/tableRows.ts` и `diagram/tableShapes.ts` (строки индексов, значок, линия
  блока), `diagram/editor.ts` (раскладка с блоком, `addTableIndex`, `setIndexProps`, состояние выделенного индекса,
  запрет связей к строке индекса), `diagram/baseTables.ts` (строки индексов не наследуются), `diagram/TableTools.tsx`,
  `diagram/FieldPopover.tsx`, `diagram/canvasMenu.ts`, `templates/builder.ts`, `drawio/style.ts`.
- `backend`, `collab` не меняются; новых зависимостей нет.
