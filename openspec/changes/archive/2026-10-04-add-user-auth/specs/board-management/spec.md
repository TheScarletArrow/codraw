# Spec Delta

## MODIFIED Requirements

### Requirement: Список досок

Система SHALL возвращать по запросу `GET /api/boards` список досок текущего пользователя,
отсортированный по времени последнего изменения, начиная с самых свежих.

#### Scenario: Несколько досок

- **WHEN** у пользователя есть доски A и B, и B изменялась позже A
- **THEN** `GET /api/boards` возвращает B раньше A

#### Scenario: Досок нет

- **WHEN** пользователь ещё не создал ни одной доски
- **THEN** `GET /api/boards` возвращает статус 200 и пустой список

#### Scenario: Чужие доски не попадают в список

- **WHEN** у пользователя A есть доска, а пользователь B запрашивает `GET /api/boards`
- **THEN** доски пользователя A нет в ответе
