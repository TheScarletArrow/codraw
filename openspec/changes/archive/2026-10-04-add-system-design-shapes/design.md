## Context

Палитра описана пресетами в `shapes.ts` по разделам, фигуры, которых нет в maxGraph, регистрируются в
`extensions.ts` (`document`, `mxgraph.c4.person2`, прямоугольник с пропуском щелчков). Требования — в `specs/`.

## Goals / Non-Goals

**Goals:**

- Узнаваемые без подписи фигуры для типовых элементов системного дизайна, нарисованные векторно, как
  остальные фигуры: масштабируются, перекрашиваются выбором цвета и синхронизируются как стиль.
- Совместимость с draw.io там, где у draw.io есть подходящая базовая фигура.

**Non-Goals:**

- Иконки облачных провайдеров (AWS, GCP, Azure) и Kubernetes-объектов как в библиотеках draw.io.
- Изображения из внешних адресов: фигуры рисуются кодом, а не картинками.
- Поиск по палитре и сохранение свёрнутых разделов между открытиями доски.

## Decisions

### Фигуры

| Раздел | Фигура | Стиль |
|---|---|---|
| Инфраструктура | Балансировщик нагрузки | `hexagon` (maxGraph) |
| | API-шлюз | `process` — прямоугольник с полосами по бокам |
| | CDN | `doubleEllipse` (maxGraph) |
| | Сервер | `codraw.server` — стойка из трёх блоков с индикаторами, подпись снизу |
| | Контейнер | `cube` |
| | Кластер Kubernetes | рамка как у «Границы», скруглённая, `pointerEvents=0` |
| | Брандмауэр | `codraw.firewall` — кирпичная стена, подпись снизу |
| | DNS | `card` — карточка со срезанным углом |
| Данные и сообщения | Хранилище объектов | `codraw.bucket` — ведро, подпись снизу |
| | Поисковый индекс | `internalStorage` |
| | Хранилище данных | `datastore` — цилиндр из нескольких дисков |
| | Топик событий | `codraw.topic` — лента из сегментов |
| | Планировщик задач | `codraw.clock` — циферблат, подпись снизу |
| | Функция | `parallelogram` |
| Клиенты | Веб-браузер | `codraw.browser` — окно со строкой адреса |
| | Мобильное приложение | `codraw.mobile` — телефон, подпись снизу |
| | Десктоп-приложение | `codraw.desktop` — монитор на подставке, подпись снизу |
| | IoT-устройство | `codraw.chip` — микросхема с выводами, подпись снизу |
| UML | Компонент | `component` — прямоугольник с двумя выступами слева |
| | Интерфейс | `ellipse` 30×30, подпись снизу |
| | Пакет | `folder` — папка с вкладкой |
| | Заметка | `note` — лист с загнутым углом, жёлтая заливка |

- Имена `process`, `cube`, `card`, `internalStorage`, `datastore`, `parallelogram`, `component`, `folder`,
  `note` совпадают с базовыми фигурами draw.io, и рисуются они похоже. Для фигур без аналога — префикс
  `codraw.`, чтобы не спутать их с фигурами draw.io.
- Фигуры-«иконки» (сервер, ведро, клиенты) подписываются под фигурой, как «Пользователь»; «коробки»
  подписываются внутри.
- Каждая фигура — подкласс `ActorShape` (путь) или `Shape` (несколько частей) в `extensions.ts`; заливка
  и обводка берутся из стиля, поэтому выбор цвета работает для всех.
- Альтернатива — картинки-иконки через `shape=image`. Отклонена: картинку нельзя перекрасить выбором цвета,
  а адрес картинки из документа — ещё один путь загрузить в браузер участников внешний ресурс.

### Палитра

- Разделы становятся `<details open>` с заголовком в `<summary>`: сворачивание без своего состояния,
  с доступностью из коробки. Все разделы развёрнуты при открытии доски.

## Risks / Trade-offs

- [Фигуры `codraw.*` неизвестны draw.io] → при экспорте `.drawio` их придётся заменить на ближайшие
  базовые фигуры или картинки; это задача экспорта.
- [Похожесть базовых фигур на draw.io приблизительная] → совпадают имена и общий вид; точная геометрия
  draw.io (например, параметр `size`) не воспроизводится.
- [Палитра стала длинной] → разделы сворачиваются.
