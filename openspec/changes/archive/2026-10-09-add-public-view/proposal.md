## Why

Сейчас доску по ссылке открывает только вошедший пользователь или гость, нажавший «Продолжить без входа», — и гость
при этом становится пользователем CoDraw и участником доски. Читателю README, страницы Confluence или `<iframe>` на сайте
это лишний шаг, а «Живая картинка» даёт только SVG одной страницы — без остальных страниц, масштаба и прокрутки.
Режим ссылки «Все, у кого есть ссылка, без входа» делает доску документом, который можно показать кому угодно (issue
#60).

## What Changes

- Четвёртый режим доступа по ссылке `public` — «Все, у кого есть ссылка, без входа»: доску смотрит любой, у кого есть
  ссылка, без входа и без правки. Вошедшим, в том числе гостям, он даёт то же, что «Просмотр» (`viewer`); участники
  сохраняют свои личные роли. Владелец включает и выключает режим в окне «Поделиться», как остальные.
- Публичный просмотр `/view/{id}`: холст со всеми страницами, масштабом и прокруткой, только для чтения — без
  присутствия, комментариев, запросов доступа и создания гостя. Посетитель без сеанса, открывший обычную ссылку доски
  `/boards/{id}` в режиме `public`, попадает на него вместо страницы входа; кнопка «Войти» ведёт к входу и обратно на
  доску. Просмотр подтягивает новое состояние доски раз в минуту и при возвращении на вкладку, не сбрасывая масштаб.
- `backend`: открытые без входа эндпоинты только на чтение — `GET /api/public/boards/{id}` (название) и
  `GET /api/public/boards/{id}/document` (состояние документа Yjs с `ETag`); для доски не в режиме `public`, в корзине
  или несуществующей — 404. Картинки доски в режиме `public` отдаются без входа.
- Окно «Поделиться» в режиме `public` показывает код `<iframe>` для встраивания и кнопку «Копировать код».
- nginx разрешает встраивать в чужие страницы только адреса `/view/…` (`frame-ancestors *`, без `X-Frame-Options`);
  остальное приложение по-прежнему встраивать нельзя.
- `collab` даёт вошедшим по ссылке в режиме `public` соединение только для чтения.
- Политика конфиденциальности и условия использования говорят, что доску в режиме `public` видит любой, у кого есть
  ссылка, без входа.

## Capabilities

### New Capabilities

- `public-view`: просмотр доски без входа по ссылке и во `<iframe>` — страница просмотра, открытые эндпоинты только на
  чтение, встраивание.

### Modified Capabilities

- `board-access`: режим ссылки `public` и роль, которую он даёт; выбор режима и код встраивания в окне «Поделиться».
- `canvas-images`: картинки доски в режиме `public` отдаются без входа.
- `legal-pages`: политика и условия говорят о доске, открытой без входа.

## Impact

- `backend`: миграция (значение `PUBLIC` в проверке `boards.link_access`), `LinkAccess.PUBLIC`, контроллер
  `/api/public/boards/**`, открытый `GET` картинок доски в режиме `public`, правила безопасности, тесты.
- `collab`: тип `LinkAccess` и право `view` для режима `public`, тесты.
- `frontend`: маршрут `/view/:boardId` (страница просмотра), переход с `/boards/:id` без сеанса, режим в окне
  «Поделиться» с кодом `<iframe>`, политика и условия, «Что нового», тесты.
- `frontend/nginx`: заголовки, разрешающие встраивать `/view/…`; проверка стека.
- e2e: просмотр без входа, картинки, переход с обычной ссылки, закрытие режима.
- README, `docs/running.md`, «План работ».
