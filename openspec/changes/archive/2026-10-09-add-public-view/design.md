## Context

Доступ к доске — роль: владелец, личная роль участника и то, что даёт режим ссылки (`none`, `view`, `edit`). Режим
хранится в `boards.link_access` с проверкой значений, `collab` получает его через внутренний API и сам считает право
соединения (`accessOf`). Без сеанса `backend` отвечает 401 на всё, кроме открытых адресов (`/api/embeds/**`,
`/api/legal`, вход гостя), а `Layout` фронтенда отправляет посетителя без сеанса на `/login`. Документ доски для
`backend` — непрозрачное состояние Yjs в `board_documents`, которое `collab` сохраняет с задержкой в пару секунд после
правок. Состояние доски уже показывается только для чтения без соединения: просмотр версий собирает `Y.Doc` из
состояния и рисует его `DiagramCanvas` с `readOnly`. Картинки доски лежат по адресам `/api/boards/{id}/images/{imageId}`,
которые хранятся в стилях фигур, и отдаются только с ролью на доске. nginx отдаёт всем страницам приложения
`frame-ancestors 'none'` и `X-Frame-Options: DENY`.

## Goals / Non-Goals

**Goals:**

- Ссылка на доску, которую открывает кто угодно без входа и без создания гостя, — для README, Confluence и `<iframe>`.
- Все страницы, масштаб и прокрутка, как у участника в режиме «Просмотр», но без присутствия и комментариев.
- Отдельный путь в `backend` только на чтение документа; ничего из открытого API не меняет доску.

**Non-Goals:**

- Живое соединение для читателя без входа (присутствие, курсоры, мгновенные правки) — читатель подтягивает состояние
  раз в минуту.
- Отдельный секретный ключ публичной ссылки, как у живой картинки: ссылка — это адрес доски.
- Сочетание «правка по ссылке для вошедших и просмотр без входа» в одном режиме; правку дают личные роли участников.
- Экспорт, копирование в другую доску и поиск по доске на странице просмотра без входа.
- Ограничение частоты запросов к открытым эндпоинтам сверх того, что даёт `ETag`.

## Decisions

### Четвёртый режим ссылки, а не отдельный переключатель

`LinkAccess.PUBLIC("public", BoardRole.VIEWER)`: режим отвечает на один вопрос — что ссылка даёт тем, кто не владелец и
не участник; `public` даёт им просмотр, в том числе без входа. Роль вошедших считается, как раньше, через `Board.roleOf`,
поэтому списки «Общие со мной», поиск, уведомления, запросы доступа и «Открывали по ссылке» работают без изменений
(они сравнивают режим с `NONE`). `collab` считает `public` правом `view`. Миграция заменяет проверку
`boards_link_access_check` на список с `PUBLIC`; откат переводит `PUBLIC` в `VIEW` и возвращает прежнюю проверку.

Альтернатива — флаг `public_view` рядом с режимом. Отклонена: даёт противоречивые сочетания («Только я», но смотреть
может кто угодно без входа; вошедший пользователь без роли получает «Нет доступа», хотя выйдя из учётной записи доску
увидит) и требует второго правила доступа во всех местах, где сейчас достаточно роли. Цена выбора — команда, которая
правит доску по ссылке, при `public` правит её как участники (приглашение или «Добавить» в «Открывали по ссылке»).

### Открытый API только на чтение

- `PublicBoardController`: `GET /api/public/boards/{id}` → `{id, title, updatedAt}`, `GET /api/public/boards/{id}/document`
  → байты состояния (`application/octet-stream`), 204 без документа. Доска ищется как активная (`BoardService.find`), и
  всё, что не в режиме `public`, отвечает 404 — так открытый адрес не говорит, есть ли закрытая доска.
- `ETag` документа — время его сохранения из `board_documents.updated_at`, `Cache-Control: no-cache`: браузер сам
  переспрашивает с `If-None-Match`, а `backend` отвечает 304, не читая состояние. Проверка времени и чтение состояния —
  два запроса без транзакции: если документ сохранили между ними, тег окажется старше состояния, и следующий опрос
  получит то же состояние ещё раз — безопасно.
- В `SecurityConfiguration` — `permitAll` для `GET /api/public/**`. Эндпоинты не используют сеанс, не создают гостя и не
  пишут посещений.

### Картинки без входа

`GET /api/boards/{id}/images/{imageId:<uuid>}` открыт в правилах безопасности (шаблон с регулярным выражением, чтобы
`…/images/usage` остался закрытым), а контроллер решает сам: с сеансом — по роли, как раньше; без сеанса — только у доски
в режиме `public`, иначе 401, как было. Так адреса картинок в документе остаются прежними, и просмотру не нужно их
переписывать.

### Страница просмотра `/view/:boardId`

- Отдельный маршрут вне `Layout` (без шапки пользователя и проверки сеанса), лениво загружаемый, как страница доски.
  Запросы: название, состояние документа и `/api/me` — только чтобы понять, вошёл ли посетитель.
- Один `Y.Doc` на всё время страницы: каждое полученное состояние применяется к нему `Y.applyUpdate` — Yjs сливает его с
  прежним, холст только для чтения перерисовывает изменения, а масштаб, прокрутка и страница остаются. Опрос —
  `refetchInterval` 60 с и при возвращении на вкладку (`refetchOnWindowFocus`), запрос с `cache: 'no-cache'`.
- Холст — `DiagramCanvas` с `readOnly` и `collaboration={false}` (без указки и инструмента комментариев), над ним
  `StatusBadges`, вкладки страниц `PageTabs` с `readOnly`, панель масштаба — `EditorToolbar` с `readOnly` и
  `collaboration={false}`, где остаются только кнопки масштаба. Страница из `?page=` — начальная, выбор страницы
  заменяет `?page=` в адресе.
- Кнопка в шапке: во фрейме (`window.top !== window.self`) — «Открыть в CoDraw» на `/boards/{id}?page=…` в новой
  вкладке; вошедшему — «Открыть доску» туда же; иначе — «Войти» на `/login` с возвратом на `/boards/{id}?page=…`.
- Доска не в режиме `public` (404): во фрейме — «Доска недоступна без входа» и «Открыть в CoDraw»; вошедший переходит
  на `/boards/{id}` (там его роль решает, что он увидит); посетитель без сеанса — на `/login` с возвратом на
  `/boards/{id}`. Петли нет: `Layout` отправляет на `/view/…` только посетителя без сеанса.
- `Layout`: без сеанса на `/boards/:boardId` (не на предложениях) — переход на `/view/:boardId` с тем же `?page=`, а не на
  `/login`.

### Встраивание

`map $request_uri` в шаблоне nginx даёт для `/view/…` `frame-ancestors *` и пустой `X-Frame-Options` (nginx не
отправляет заголовок с пустым значением), для остального — прежние `'none'` и `DENY`. `$request_uri` — адрес запроса
до `try_files`, поэтому и `index.html`, отданный на `/view/…`, получает разрешающие заголовки. Внутри фрейма приложение
не уходит со страницы просмотра: кнопки открывают CoDraw в новой вкладке, поэтому кликджекингу подвержена только
страница без действий.

### Окно «Поделиться»

Четвёртый вариант «Все, у кого есть ссылка, без входа» среди режимов; у остальных участников — «По ссылке доску можно
смотреть без входа». В режиме `public` под режимами — поле «Код для встраивания» с `<iframe src="…/view/{id}?page=…"
width="800" height="600" style="border:0" allowfullscreen></iframe>` и кнопкой «Копировать код».

## Risks / Trade-offs

- [Читатель видит состояние с задержкой: `collab` сохраняет документ через пару секунд после правок, а просмотр
  опрашивает раз в минуту] → для README и вики этого достаточно; живое соединение — отдельная задача.
- [Состояние Yjs содержит всё, что есть в документе, в том числе имена тех, кто менял элементы, и скрытые слоями
  элементы] → режим включает владелец явно, описание режима и политика конфиденциальности говорят, что доску видит
  любой; комментарии, участники и решения в документе не хранятся и не отдаются.
- [Открытый адрес отдаёт документ до предела размера доски (32 МБ) без входа] → `ETag` и 304 для повторных запросов,
  опрос раз в минуту; ограничение частоты при необходимости — на прокси перед установкой.
- [Режим `public` убирает правку по ссылке] → участники с личной ролью правят дальше; описание режима в окне это
  говорит.
- [Откат миграции] → доски в режиме `public` становятся `view`: вошедшие смотрят их, как раньше, без входа — нет.

## Migration Plan

Миграция `V26`/`U26` (номер `V25` занят открытым изменением задач GitHub): только проверка значений столбца, данные не
меняются. `frontend`, `backend` и `collab` выкатываются вместе, как обычно; старый `collab` с новым `backend` отклонил бы
соединения вошедших к доскам в режиме `public` — до выкатки `collab` режим просто не выбирают.
