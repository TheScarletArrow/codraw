# Spec Delta

## MODIFIED Requirements

### Requirement: Фигуры архитектуры

Раздел «Архитектура» SHALL содержать фигуры «Сервис», «База данных» (цилиндр), «Очередь», «Кэш»,
«Пользователь», «Внешняя система» (облако), «Документ», «Граница» и «Легенда». Каждая фигура, кроме легенды, SHALL
добавляться с подписью, совпадающей с её названием; легенда — с заголовком «Легенда».

#### Scenario: Добавление базы данных

- **WHEN** участник добавляет «Базу данных» из раздела «Архитектура»
- **THEN** на холсте появляется цилиндр с подписью «База данных»

### Requirement: Фигуры C4

Раздел «C4» SHALL содержать фигуры Person, Software System, Container, Component, Database,
External System и границу системы в цветах нотации C4 и «Легенду». Подпись фигуры C4 SHALL состоять из имени, типа
в квадратных скобках и описания на отдельных строках и редактироваться как обычная подпись.

#### Scenario: Добавление контейнера C4

- **WHEN** участник добавляет Container из раздела «C4»
- **THEN** на холсте появляется синий прямоугольник со скруглёнными углами и подписью из трёх строк:
  «Контейнер», «[Container: технология]» и «Описание»

#### Scenario: Легенда в разделе C4

- **WHEN** участник ищет в разделе «C4» фигуру «Легенда»
- **THEN** она есть, и поиск фигур по слову «легенда» находит её один раз
