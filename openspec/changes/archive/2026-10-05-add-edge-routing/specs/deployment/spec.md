# Spec Delta

## MODIFIED Requirements

### Requirement: Заголовки безопасности

Ответы с приложением SHALL содержать `Content-Security-Policy`, которая разрешает скрипты, стили, подключения
и шрифты только с адреса приложения и компиляцию WebAssembly из них (`'wasm-unsafe-eval'`), а также
`X-Content-Type-Options: nosniff`, `Referrer-Policy` и запрет показа во фрейме. Приложение SHALL работать с этой
политикой без её нарушений. Файлы сборки с хешем в имени SHALL кешироваться браузером на год, а страница приложения
SHALL проверяться при каждом открытии.

#### Scenario: Политика не мешает приложению

- **WHEN** пользователь входит, создаёт доску, добавляет фигуры, связывает таблицы и работает вместе с другим участником
- **THEN** браузер не сообщает о нарушениях Content Security Policy, и связи прокладываются в обход фигур

#### Scenario: Кеширование

- **WHEN** браузер запрашивает страницу приложения и файл сборки из `/assets/`
- **THEN** страница приходит с `Cache-Control: no-cache`, а файл — с `max-age` в год и `immutable`
