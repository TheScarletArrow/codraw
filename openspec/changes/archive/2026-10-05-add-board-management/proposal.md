# Proposal

## Why

Доску в CoDraw можно только создать: её нельзя переименовать, и она навсегда остаётся в списке, даже если создана
по ошибке. Название «Новая доска» достаётся каждой новой доске, и через неделю список состоит из одинаковых строк.
Чужую доску участник открывает по ссылке, но в его списке её нет: закрыв вкладку, он теряет доску, если не сохранил
ссылку.

## What Changes

- `backend`: владелец переименовывает доску (`PATCH /api/boards/{id}`) и удаляет её вместе с документом
  (`DELETE /api/boards/{id}`); остальным участникам это запрещено.
- `backend`: сведения о доске сообщают её владельца и роль текущего пользователя: `owner` или `editor`.
- `backend`: система запоминает, какие чужие доски пользователь открывал по ссылке, и возвращает их списком
  `GET /api/boards/shared`, недавно открытые первыми. При входе через провайдера из гостевого сеанса этот список
  переходит к аккаунту, как и доски гостя.
- `frontend`: на главной странице у своих досок есть меню «Переименовать» и «Удалить» с подтверждением; ниже — раздел
  «Открытые по ссылке» с именем владельца каждой доски.
- `frontend`: на странице доски владелец переименовывает её щелчком по названию и удаляет из меню доски.
- `frontend` и `collab`: новое название видят все подключённые участники без перезагрузки. Участники удалённой доски
  видят «Доска не найдена»: сразу, если доску удалили с её страницы, и не позже своей следующей правки, если из списка.
  Правки удалённой доски не сохраняются.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `board-management`: сведения о доске дополняются владельцем и ролью; новые требования — переименование и удаление
  доски, список досок, открытых по ссылке, управление досками из интерфейса.
- `realtime-sync`: новые требования — новое название доски доходит до подключённых участников, участники удалённой
  доски узнают об удалении.
- `user-auth`: при переносе досок гостя к аккаунту переходит и список досок, открытых гостем по ссылке.

## Impact

- `backend`: `BoardController`, `BoardService` (переименование, удаление, проверка владельца), новая таблица
  `board_visits` и пара миграций V/U, `UserService.signIn` (перенос посещений гостя). API: новые `PATCH` и `DELETE`
  для `/api/boards/{id}`, новый `GET /api/boards/shared`, новые поля `owner` и `role` в ответах о доске.
- `collab`: пересылка служебного сообщения `board-changed` участникам документа; закрытие соединений документа, когда
  `backend` отвечает 404 на сохранение.
- `frontend`: `api/boards.ts`, `BoardsPage.tsx`, `BoardPage.tsx`, `useBoardConnection.ts`, новые компоненты
  переименования и меню доски.
- Удаление доски необратимо: корзины нет.
