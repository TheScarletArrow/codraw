## ADDED Requirements

### Requirement: Пределы одного импорта

Экземпляр `backend` SHALL выполнять не больше `codraw.schema-import.max-concurrent-imports` (по умолчанию 2) импортов
одновременно и отвечать на следующий 429 с `Retry-After`. Импорт SHALL длиться не дольше
`codraw.schema-import.import-timeout` (по умолчанию 60 секунд): затем его соединение закрывается, что бы ни присылал
сервер. Имя базы, пользователь и схема SHALL NOT содержать управляющих символов (400). Адреса общего пространства
операторов (`100.64.0.0/10`), адреса метаданных облаков по IPv6 и адреса IPv6 с вложенным IPv4 (NAT64, 6to4) SHALL
открываться только записями внутри этих диапазонов, как остальные особые адреса.

#### Scenario: Сервер не отвечает до конца

- **WHEN** сервер базы начал ответ и присылает его по байту
- **THEN** импорт заканчивается ошибкой не позже срока импорта, и соединение закрыто

#### Scenario: Управляющие символы

- **WHEN** пользователь базы содержит перевод строки
- **THEN** ответ 400 «Invalid field of the connection: user», и подключения нет

#### Scenario: Метаданные облака при широкой сети

- **WHEN** разрешена сеть `0.0.0.0/0`, и пользователь подключается к `100.100.100.200`
- **THEN** ответ 403 `host-not-allowed`
