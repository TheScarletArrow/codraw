# Spec Delta

## ADDED Requirements

### Requirement: Имена участников из профиля

Участники доски SHALL отображаться в списке участников и у курсоров под именем и с аватаром из своего
профиля. Цвет участника SHALL быть одинаковым при каждом входе.

#### Scenario: Вошедший пользователь открывает доску

- **WHEN** пользователь, вошедший через GitHub, открывает доску
- **THEN** остальные участники видят его имя и аватар из профиля GitHub

## REMOVED Requirements

### Requirement: Имя и цвет гостя

**Reason**: После входа в систему у каждого участника есть имя из профиля, анонимных гостей нет.
**Migration**: Используется требование «Имена участников из профиля».
