# Design

## Context

Панель фигур — `ShapePalette`: разделы `<details>` из `SHAPE_SECTIONS` с кнопками, которые добавляют фигуру щелчком
или перетаскиванием. Фигура — `ShapePreset` с идентификатором на английском (`object-storage`) и русским названием.
Клавиши редактора привязаны в `KeyHandler` (`editor.ts`), подсказки клавиш в меню правого щелчка пишутся через
`shortcutLabel` с `Mod` вместо Ctrl или ⌘. Требования — в `specs/`.

## Goals / Non-Goals

**Goals:**

- Найти фигуру по слову разработчика, а не только по её русскому названию.
- Одна справка по всем клавишам, которая не расходится с редактором.

**Non-Goals:**

- Поиск по фигурам библиотек draw.io, которых нет в CoDraw, и нечёткий поиск с опечатками.
- Смена горячих клавиш пользователем.
- Клавиша фокуса поиска: Ctrl+F — поиск браузера, а `/` нужен в подписях.

## Decisions

### Поиск фигур

- Слова поиска фигуры — её название, идентификатор (дефисы как пробелы), название раздела и список синонимов в
  `shapeSearch.ts`: технологии (`redis`, `kafka`, `postgres`, `s3`, `nginx`, `k8s`), английские и русские названия.
  Синонимы лежат отдельно от `ShapePreset`, чтобы не раздувать описания фигур и не влиять на документ.
- Сравнение — без учёта регистра, «ё» как «е». Запрос делится на слова; фигура подходит, если каждое слово запроса —
  начало одного из её слов. Начало слова, а не подстрока: «db» не должен находить «Хранилище данных» через «feedback».
- Порядок: сначала фигуры, у которых совпало название, затем остальные, внутри — в порядке панели.
- Пока поле не пусто, разделы скрыты, а найденные фигуры — один список кнопок той же вёрстки. Enter добавляет первую
  найденную фигуру в центр видимой области, Escape очищает поле. Пустой результат — «Ничего не найдено».

### Справка по клавишам

- Привязки клавиш редактора становятся данными: `KEY_BINDINGS` в `editor.ts` — клавиши в записи с `Mod`, признак
  «только для правки» и действие; `KeyHandler` получает их в цикле.
- `shortcuts.ts` — группы клавиш с действиями для справки, в той же записи. Тест сверяет её клавиши с
  `KEY_BINDINGS` (вместе с признаком правки), чтобы справка не расходилась с клавишами; Ctrl+C, Ctrl+X, Ctrl+V — события
  буфера, а не привязки, и мышь в сверку не входят.
- Запись клавиш — `formatKeys`: Ctrl, Shift, Alt на Windows и Linux, ⌘, ⇧, ⌥ на macOS; стрелки — ←↑→↓.
- Окно — `Popover` от кнопки «Горячие клавиши» в шапке (роль `dialog`, Escape закрывает). Клавиша `?` открывает
  и закрывает его, если фокус не в поле ввода и не в правке подписи: обработчик `keydown` документа смотрит на `key`.
- Альтернатива — отдельная страница справки. Отклонена: справка нужна, не уходя с доски.

## Risks / Trade-offs

- [Синонимы устаревают, когда появляются новые фигуры] → `SHAPE_KEYWORDS` — запись по всем `ShapeId`: новая фигура
  без слов поиска не соберётся.
- [`?` набирают на русской раскладке как `,` с Shift] → обработчик смотрит на `key === '?'`, а на русской раскладке
  `?` — Shift+7, что тоже даёт `key === '?'`.
