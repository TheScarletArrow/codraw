# Spec Delta

## MODIFIED Requirements

### Requirement: Доступ к доске по ссылке

Любой аутентифицированный пользователь, в том числе гость, SHALL получать доску по её идентификатору, то есть
открывать её по ссылке, если владелец не закрыл доступ по ссылке: в режиме `edit` он работает с доской как редактор,
в режиме `view` только смотрит её. В режиме `none` доску получает только владелец, остальные получают статус 403.
Доска, которой не существует, SHALL получать статус 404.

#### Scenario: Открытие доски другого пользователя по ссылке

- **WHEN** пользователь B открывает ссылку на доску пользователя A в режиме `edit`
- **THEN** `GET /api/boards/{id}` отвечает статусом 200 с ролью `editor`, и B редактирует доску вместе с A, а в списке
  досок B этой доски нет

#### Scenario: Доска только для просмотра

- **WHEN** пользователь B открывает ссылку на доску пользователя A в режиме `view`
- **THEN** `GET /api/boards/{id}` отвечает статусом 200 с ролью `viewer`

#### Scenario: Доступ по ссылке закрыт

- **WHEN** доска пользователя A в режиме `none`, и её запрашивают A и пользователь B
- **THEN** A получает статус 200, а B — статус 403

#### Scenario: Несуществующая доска

- **WHEN** пользователь запрашивает `GET /api/boards/{id}` доски, которой нет
- **THEN** ответ имеет статус 404

### Requirement: Токен доступа к синхронизации

Система SHALL выдавать аутентифицированному пользователю по запросу `POST /api/boards/{id}/collab-token`
токен доступа к документу существующей доски сроком не больше 5 минут, если пользователь может открыть эту доску.
Токен и ответ SHALL содержать роль пользователя на доске: `owner`, `editor` или `viewer`.

#### Scenario: Токен для доски

- **WHEN** пользователь запрашивает токен для своей доски или для доски, открытой по ссылке в режиме `edit`
- **THEN** ответ имеет статус 200 и содержит токен, срок действия которого истекает не позже чем через
  5 минут, и роль `owner` или `editor`

#### Scenario: Токен для доски только для просмотра

- **WHEN** пользователь B запрашивает токен для доски пользователя A в режиме `view`
- **THEN** ответ имеет статус 200, а токен и ответ содержат роль `viewer`

#### Scenario: Токен при закрытом доступе

- **WHEN** пользователь B запрашивает токен для доски пользователя A в режиме `none`
- **THEN** ответ имеет статус 403, и токен не выдаётся

#### Scenario: Токен для несуществующей доски

- **WHEN** пользователь запрашивает токен для доски, которой нет
- **THEN** ответ имеет статус 404, и токен не выдаётся

### Requirement: Подключение к синхронизации только с токеном

Сервис синхронизации SHALL принимать подключение к документу доски только с действительным токеном,
выданным для этой доски, и отклонять остальные подключения. Подключение с ролью `viewer` SHALL получать документ
и изменения других участников, но его собственные изменения документа MUST NOT применяться.

#### Scenario: Подключение без токена или с просроченным токеном

- **WHEN** клиент подключается к документу доски без токена, с просроченным токеном или с токеном
  с неверной подписью
- **THEN** соединение отклоняется, и клиент не получает содержимое документа

#### Scenario: Токен для другой доски

- **WHEN** клиент подключается к документу доски X с токеном, выданным для доски Y
- **THEN** соединение отклоняется

#### Scenario: Переподключение после истечения токена

- **WHEN** соединение владельца прервалось, и его прежний токен истёк
- **THEN** клиент сам получает новый токен и переподключается без действий пользователя

#### Scenario: Подключение только для просмотра

- **WHEN** клиент с токеном роли `viewer` подключается к документу и меняет его у себя
- **THEN** клиент получает документ и изменения других участников, а его изменение не доходит до остальных
  участников и не сохраняется

## ADDED Requirements

### Requirement: Режим доступа по ссылке

У доски SHALL быть режим доступа по ссылке: `none`, `view` или `edit`. Новая доска создаётся в режиме `edit`. Режим
возвращается в поле `linkAccess` сведений о доске, и только владелец меняет его запросом `PATCH /api/boards/{id}`
с телом `{"linkAccess": "…"}`.

#### Scenario: Новая доска

- **WHEN** пользователь создаёт доску
- **THEN** ответ содержит `linkAccess` = `edit`

#### Scenario: Владелец меняет режим

- **WHEN** владелец отправляет `PATCH /api/boards/{id}` с телом `{"linkAccess": "view"}`
- **THEN** ответ имеет статус 200 и содержит `linkAccess` = `view`, и `GET /api/boards/{id}` возвращает тот же режим

#### Scenario: Неизвестный режим

- **WHEN** владелец отправляет `PATCH /api/boards/{id}` с телом `{"linkAccess": "admin"}`
- **THEN** ответ имеет статус 400, и режим доски не меняется

#### Scenario: Режим меняет не владелец

- **WHEN** пользователь B, открывший доску пользователя A по ссылке, отправляет `PATCH /api/boards/{id}`
  с полем `linkAccess`
- **THEN** ответ имеет статус 403, и режим доски не меняется

### Requirement: Перепроверка доступа открытого соединения

Сервис синхронизации SHALL перепроверять доступ открытого соединения, запрашивая у клиента новый токен без
переподключения: до истечения срока прежнего токена и когда участник доски сообщил об изменении доски. С новой ролью
`viewer` соединение SHALL переходить в режим только для чтения, с ролью `owner` или `editor` — в режим редактирования.
Соединение, которое не прислало действительный токен в течение 10 секунд после запроса, SHALL закрываться.

#### Scenario: Соединение дольше срока токена

- **WHEN** участник работает на доске дольше срока жизни своего первого токена
- **THEN** клиент получает новый токен без переподключения, и его изменения по-прежнему доходят до остальных
  участников

#### Scenario: Владелец закрыл доступ на странице доски

- **WHEN** участник B работает на доске, а владелец A переключает её в режим `none` на странице доски
- **THEN** в течение нескольких секунд соединение B закрывается, и его изменения больше не доходят до A

#### Scenario: Владелец перевёл доску в просмотр

- **WHEN** участник B редактирует доску, а владелец A переключает её в режим `view` на странице доски
- **THEN** в течение нескольких секунд изменения B перестают применяться

#### Scenario: Клиент не прислал токен

- **WHEN** клиент не отвечает на запрос нового токена или присылает недействительный токен
- **THEN** не позже чем через 10 секунд после запроса соединение закрывается

### Requirement: Настройка доступа на странице доски

Страница доски SHALL показывать владельцу кнопку «Поделиться». Она открывает окно со ссылкой на доску, кнопкой
«Скопировать ссылку» и выбором режима доступа: «Только владелец», «Просмотр по ссылке» и «Редактирование
по ссылке». Остальным участникам эта кнопка недоступна.

#### Scenario: Владелец меняет режим

- **WHEN** владелец открывает «Поделиться» и выбирает «Просмотр по ссылке»
- **THEN** доска переходит в режим `view`, и при следующем открытии окна выбран «Просмотр по ссылке»

#### Scenario: Копирование ссылки

- **WHEN** владелец нажимает «Скопировать ссылку»
- **THEN** в буфере обмена оказывается адрес страницы доски

#### Scenario: Участник по ссылке

- **WHEN** пользователь B открыл по ссылке доску пользователя A
- **THEN** кнопки «Поделиться» у B нет

### Requirement: Режим просмотра

Участник с ролью `viewer` SHALL видеть доску, её страницы, курсоры и выделения участников и изменения в реальном
времени, но не менять документ: на странице нет палитры фигур, инструментов правки, меню холста, стрелок быстрого
соединения, правки страниц и импорта из `.drawio`, а холст не выделяет, не двигает и не удаляет объекты. Масштаб,
прокрутка, переход между страницами и к участникам и экспорт остаются. Страница SHALL показывать метку «Только
просмотр».

#### Scenario: Читатель открывает доску

- **WHEN** участник с ролью `viewer` открывает доску с фигурами
- **THEN** он видит фигуры и метку «Только просмотр», а палитры фигур и кнопок «Отменить» и «Повторить» нет

#### Scenario: Читатель не меняет доску

- **WHEN** читатель тянет фигуру мышью и нажимает Delete
- **THEN** фигура остаётся на месте и у читателя, и у владельца

#### Scenario: Читатель видит правки

- **WHEN** владелец добавляет фигуру на страницу, которую смотрит читатель
- **THEN** читатель видит новую фигуру без перезагрузки страницы

#### Scenario: Роль меняется во время работы

- **WHEN** владелец переключает доску из `edit` в `view` и обратно, пока участник B работает на ней
- **THEN** страница B без перезагрузки переходит в режим просмотра, а затем обратно в режим редактирования

### Requirement: Нет доступа к доске

Страница доски SHALL показывать «Нет доступа к доске», когда владелец закрыл доступ по ссылке: при открытии доски
и во время работы без перезагрузки страницы.

#### Scenario: Открытие закрытой доски

- **WHEN** пользователь B открывает ссылку на доску в режиме `none`
- **THEN** страница показывает «Нет доступа к доске» и не подключается к документу

#### Scenario: Доступ закрыли во время работы

- **WHEN** участник B работает на доске, и владелец закрывает доступ по ссылке на странице доски
- **THEN** страница B в течение нескольких секунд показывает «Нет доступа к доске»
