# Spec Delta

## MODIFIED Requirements

### Requirement: Получение доски

Система SHALL возвращать по запросу `GET /api/boards/{id}` идентификатор, название, время создания
и время последнего изменения доски, её владельца — идентификатор, имя и аватар, — режим доступа по ссылке и роль
текущего пользователя на доске: `owner` для владельца, `editor` для остальных в режиме `edit` и `viewer` в режиме
`view`. Пользователь, который не владеет доской в режиме `none`, SHALL получать статус 403.

#### Scenario: Доска существует

- **WHEN** клиент запрашивает `GET /api/boards/{id}` существующей доски
- **THEN** ответ имеет статус 200 и содержит `id`, `title`, `createdAt`, `updatedAt`, `linkAccess` и `owner`
  с полями `id`, `name` и `avatarUrl`

#### Scenario: Роль владельца и участника по ссылке

- **WHEN** владелец доски A и пользователь B, открывший её по ссылке, запрашивают `GET /api/boards/{id}`
- **THEN** A получает `role` = `owner`, а B — `role` = `editor` в режиме `edit` и `viewer` в режиме `view`, и оба
  получают одного и того же владельца

#### Scenario: Доступ по ссылке закрыт

- **WHEN** пользователь B запрашивает `GET /api/boards/{id}` доски пользователя A в режиме `none`
- **THEN** ответ имеет статус 403, а A по-прежнему получает доску

#### Scenario: Доска не существует

- **WHEN** клиент запрашивает доску с несуществующим идентификатором или с идентификатором не
  в формате UUID
- **THEN** ответ имеет статус 404

## ADDED Requirements

### Requirement: Закрытые доски в списке открытых по ссылке

`GET /api/boards/shared` SHALL NOT возвращать доски в режиме `none`, а ответ 403 SHALL NOT записывать открытие доски.
Когда владелец снова открывает доступ, доска, которую пользователь открывал раньше, возвращается в его список. Раздел
«Открытые по ссылке» SHALL отмечать доски, которые пользователь может только смотреть.

#### Scenario: Владелец закрыл доступ

- **WHEN** пользователь B открывал доску X пользователя A, а A переключил X в режим `none`
- **THEN** X нет в ответе `GET /api/boards/shared` для B

#### Scenario: Владелец снова открыл доступ

- **WHEN** A переключил X из режима `none` в режим `view`
- **THEN** X снова есть в ответе `GET /api/boards/shared` для B с ролью `viewer`, а раздел «Открытые по ссылке» у B
  отмечает её как доску только для просмотра

#### Scenario: Попытка открыть закрытую доску

- **WHEN** пользователь C, который раньше не открывал доску X, запрашивает её в режиме `none`, а затем A открывает
  доступ
- **THEN** X нет в ответе `GET /api/boards/shared` для C
