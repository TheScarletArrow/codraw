# Proposal

## Why

Ссылка на доску сейчас даёт любому, кто её получил, полные права на правку: владелец не может показать схему
только для просмотра или закрыть доступ, если ссылка ушла не туда. Перед публичным развёртыванием это главный
риск: случайный участник может стереть чужую доску, а undo у каждого своё, и владелец не отменит чужое удаление.
Кроме того, ссылку на доску приходится копировать из адресной строки — кнопки «Поделиться» нет.

## What Changes

- `backend`: у доски появляется режим доступа по ссылке `linkAccess`: `none` — только владелец, `view` —
  просмотр, `edit` — правка (как сейчас). Владелец меняет его запросом `PATCH /api/boards/{id}` с полем
  `linkAccess`; новые и существующие доски получают `edit`, так что поведение ссылок не меняется, пока владелец
  его не сменит.
- `backend`: роль участника по ссылке зависит от режима: `editor` или новая `viewer`. При режиме `none`
  `GET /api/boards/{id}` и выдача токена синхронизации отвечают не владельцу 403, а доска пропадает из его раздела
  «Открытые по ссылке».
- `backend`: токен синхронизации несёт право `edit` или `view`; новый внутренний запрос отдаёт `collab` владельца
  и режим доступа доски.
- `collab`: соединение с правом `view` только читает документ — правки с него отклоняются, курсор и выделение
  видны остальным. После `board-changed` `collab` сверяет права подключённых участников с текущим режимом и
  закрывает соединения с устаревшими правами: клиент переподключается с новым токеном, а без доступа видит «Нет
  доступа».
- `frontend`: кнопка «Поделиться» на странице доски: ссылка на доску с кнопкой «Копировать» и, для владельца,
  выбор режима «Только я», «Просмотр» или «Редактирование».
- `frontend`: режим просмотра — без панели фигур, инструментов правки, стрелок быстрого соединения, правки страниц
  и импорта; масштаб, прокрутка, выделение, копирование и экспорт в `.drawio` остаются. В шапке — отметка «Только
  просмотр», в разделе «Открытые по ссылке» — «просмотр» у таких досок.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `board-access`: доступ по ссылке зависит от режима доски; токен синхронизации несёт право доступа; новые
  требования — режим доступа по ссылке, просмотр без правки, смена режима у подключённых участников и окно
  «Поделиться».
- `board-management`: сведения о доске содержат режим доступа и роль `viewer`; доски с закрытым доступом пропадают
  из раздела «Открытые по ссылке».

## Impact

- `backend`: колонка `boards.link_access` и пара миграций V4/U4; `BoardController` (поле `linkAccess` в `PATCH`
  и в ответах, 403 при закрытом доступе), `BoardService`, `BoardVisits`, `CollabTokenController` и
  `CollabTokenService` (утверждение `access`), новый `GET /internal/boards/{id}/access`.
- `collab`: `auth.ts` (обязательное утверждение `access`), `server.ts` (соединения только для чтения, сверка прав
  после `board-changed`), `backend-client.ts` (запрос режима доступа).
- `frontend`: `api/boards.ts`, `BoardPage.tsx`, `useBoardConnection.ts`, `DiagramCanvas.tsx`, `editor.ts`,
  `EditorToolbar.tsx`, `CanvasMenu`, `PageTabs.tsx`, `DrawioActions.tsx`, `BoardsPage.tsx`, новый компонент
  «Поделиться».
- Токены, выданные до обновления, не содержат `access` и после обновления `collab` не принимаются; клиент сам
  запрашивает новый токен при переподключении, а старые живут не дольше 5 минут.
