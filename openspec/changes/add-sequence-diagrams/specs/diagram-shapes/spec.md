# Spec Delta

## MODIFIED Requirements

### Requirement: Фигуры UML

Раздел «UML» SHALL содержать фигуры «Компонент», «Интерфейс», «Пакет» и «Заметка» в нотации UML, каждая —
с подписью, совпадающей с её названием, и «Диаграмму последовательности» (см. `sequence-diagrams`). Заметка SHALL быть
жёлтым листом с загнутым углом. Поиск фигур SHALL находить диаграмму последовательности по словам «sequence»,
«последовательность», «сценарий» и «сага».

#### Scenario: Добавление заметки

- **WHEN** участник добавляет «Заметку»
- **THEN** на холсте появляется жёлтый лист с загнутым правым верхним углом и подписью «Заметка»

#### Scenario: Поиск диаграммы последовательности

- **WHEN** участник вводит в поиск фигур «sequence»
- **THEN** панель показывает «Диаграмму последовательности»
