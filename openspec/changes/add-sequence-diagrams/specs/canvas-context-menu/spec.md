# Spec Delta

## ADDED Requirements

### Requirement: Меню диаграммы последовательности

Меню правого щелчка SHALL предлагать для частей диаграммы последовательности свои пункты:

- диаграмма — «Изменить подпись», «Добавить участника», «Добавить сообщение», «Скопировать Mermaid», затем пункты
  фигуры без «Свойств…»;
- участник — «Изменить», «Добавить участника справа», «Добавить сообщение», «Комментировать», «Удалить участника»;
- сообщение — «Изменить», «Добавить сообщение ниже», «Добавить заметку ниже», группа «Рамка» с `alt`, `opt`, `loop` и
  `par`, «Комментировать», «Удалить сообщение»;
- заметка — «Изменить», «Добавить сообщение ниже», «Комментировать», «Удалить заметку»;
- рамка и ветка — «Изменить условие», «Добавить ветку» (у `alt`, `par` и `critical`), «Комментировать», «Удалить рамку»
  или «Удалить ветку».

Участнику в режиме «Просмотр» меню частей SHALL давать только «Скопировать Mermaid» и «Комментировать».

#### Scenario: Меню сообщения

- **WHEN** участник щёлкает правой кнопкой по сообщению
- **THEN** меню содержит «Изменить», «Добавить сообщение ниже», «Добавить заметку ниже», группу «Рамка» с `alt`,
  `opt`, `loop` и `par` и «Удалить сообщение»

#### Scenario: Обернуть в цикл

- **WHEN** участник выбирает в меню сообщения `loop`
- **THEN** сообщение в рамке `loop`, и открыт ввод условия рамки

#### Scenario: Скопировать Mermaid читателем

- **WHEN** участник в режиме «Просмотр» щёлкает правой кнопкой по диаграмме и выбирает «Скопировать Mermaid»
- **THEN** в буфере обмена текст `sequenceDiagram` этой диаграммы
