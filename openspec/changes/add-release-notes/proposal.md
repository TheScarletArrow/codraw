# Proposal

## Why

CoDraw меняется каждый день, но пользователь узнаёт о новом, только если случайно наткнётся на кнопку. Прозрачность
заливки, шрифты, индексы таблиц появляются незаметно, а описание изменений есть только в `openspec/` и README — для
разработчиков, не для тех, кто рисует схемы.

## What Changes

- У приложения есть номер версии — `version` в `frontend/package.json`, сейчас `0.4.0`.
- Описание версий для пользователей — `frontend/src/releaseNotes/releases.ts`: по версии с датой и новинками (название
  и одна-две фразы языком интерфейса), новые сверху. Первая запись — текущая версия приложения.
- Кнопка «Что нового» в шапке приложения открывает окно со всеми версиями, новые сверху.
- После обновления окно открывается само один раз и показывает версии, вышедшие с последней показанной в этом
  браузере, с кнопкой «Все версии». Браузер помнит последнюю показанную версию в `localStorage`. Новому браузеру окно
  не открывается; браузеру, где CoDraw уже работал до появления окна (есть копии досок), показывается последняя версия.
- Записи заполнены версиями 0.1.0–0.4.0 по уже сделанным изменениям.
- Каждое изменение, которое заметит пользователь, добавляет новинку в следующую версию и поднимает версию в
  `frontend/package.json`.
- Политика конфиденциальности называет запись версии в `localStorage`.

## Capabilities

### New Capabilities

- `release-notes`: номер версии приложения и окно «Что нового».

### Modified Capabilities

- нет

## Impact

- `frontend`: `releaseNotes/` (записи, логика показа, окно), `Layout.tsx`, `offline/localCopies.ts`
  (`keepsLocalCopies`), `legal/PrivacyPage.tsx`, `package.json`.
- `backend`, `collab` не меняются; новых зависимостей нет.
