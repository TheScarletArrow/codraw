# Design

## Context

Стиль ячейки — вложенная Y.Map `style` с ключами стиля maxGraph, которые совпадают с ключами draw.io; `writeCell`
меняет только отличающиеся ключи, так что одновременные правки разных ключей сливаются. Цвета и размер текста уже
меняются так: команда редактора правит стиль выделенных ячеек в одном изменении модели, панель инструментов читает
состояние выделения из `editor.getState()`. Связи по умолчанию ортогональные — `edgeStyle: orthogonalEdgeStyle` в
стиле связей по умолчанию; импорт `.drawio` пишет прямым связям `edgeStyle: none`. Требования — в `specs/`.

## Goals / Non-Goals

**Goals:**

- Те же ключи стиля, что у draw.io: файлы ходят туда и обратно без потерь.
- Один шаг отмены на одно действие, как у цветов и размера текста.

**Non-Goals:**

- Произвольные шаблоны пунктира, стрелки и маркеры (они уже есть), тени, скругление углов фигур.
- Шрифт и выравнивание по вертикали.
- Начертание части подписи: подписи — простой текст.

## Decisions

### Ключи стиля

| Свойство | Значение | Ключи |
|---|---|---|
| Толщина | 1–20 | `strokeWidth` (1 — ключа нет) |
| Вид | сплошная / пунктир / точки | нет ключей / `dashed: true` / `dashed: true`, `dashPattern: '1 2'` |
| Форма связи | прямая / ортогональная / кривая | `edgeStyle: 'none'` / нет ключей / `curved: true` |
| Начертание | жирный, курсив, подчёркнутый | биты 1, 2, 4 в `fontStyle` (0 — ключа нет) |
| Выравнивание | влево / по центру / вправо | `align: 'left'` / нет ключа / `align: 'right'` |

- Значение по умолчанию записывается удалением ключа: стиль не растёт от «сброса», а экспорт и так дописывает
  умолчания CoDraw, которых нет в draw.io (`edgeStyle=orthogonalEdgeStyle`).
- Чтение: пунктир с шаблоном `1 2` — «Точки», с любым другим шаблоном или без него — «Пунктир»; форма — «Кривая» при
  `curved`, «Прямая» при `edgeStyle: none`, «Ортогональная» без `edgeStyle` или с `orthogonalEdgeStyle`; другие
  стили маршрута из draw.io (`elbowEdgeStyle` и т. п.) — не одна из трёх, панель показывает пустое значение.
- Выравнивание читается из итогового стиля ячейки (`graph.getCellStyle`): без ключа — по центру, как у фигур и связей
  по умолчанию. Поля таблиц получают `align: left` при создании, поэтому «по центру» у них тоже означает удаление
  ключа.

### Команды редактора

- `setLineStyle({ width?, dash?, edgeShape? })` — по выделенным ячейкам; `edgeShape` — только по связям.
  `toggleFontStyle('bold' | 'italic' | 'underline')` и `setTextAlign(align)` — по тем же ячейкам, что размер текста:
  выделенные и поля выделенных таблиц.
- Каждая команда — одно изменение модели (`batchUpdate`), то есть одна транзакция Yjs и один шаг отмены. После
  начертания вызывается подгонка автоширины в том же изменении, как после размера текста; `cssFont` уже учитывает
  жирный и курсив при измерении подписи.
- Клавиши Ctrl+B, Ctrl+I, Ctrl+U привязаны к `KeyHandler` maxGraph, который не получает клавиши, пока правится
  подпись: в поле правки они остаются клавишами браузера, как Ctrl+C и Ctrl+V.

### Состояние и панель

- `EditorState.line`: `{ width, dash, edgeShape }` или `null` без выделения; значение, разное у выделенных, — `null`;
  `edgeShape` — `null`, если связей нет или формы разные, и признак `hasEdges`.
- `EditorState.text` дополняется `bold`, `italic`, `underline` (все выделенные с текстом имеют начертание) и `align`.
- «Стиль линии» — кнопка с `Popover` рядом с «Линией» (цветом): поле толщины (`NumberField`, 1–20), три кнопки вида и,
  при связях, три кнопки формы с `aria-pressed`. Кнопки начертания и выравнивания — в группе текста рядом с размером.

## Risks / Trade-offs

- [Панель инструментов становится длиннее] → она уже прокручивается по горизонтали; стиль линии спрятан во всплывающее
  окно, на панели — одна кнопка.
- [Ctrl+U в браузере открывает исходный код страницы] → `KeyHandler` поглощает событие на холсте; вне холста клавиша
  работает как обычно.
- [Кривая связь с точками изгиба выглядит не так, как в draw.io] → maxGraph и draw.io рисуют `curved` одинаково:
  draw.io основан на mxGraph.
