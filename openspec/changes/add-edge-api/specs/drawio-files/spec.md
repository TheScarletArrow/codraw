# Spec Delta

## ADDED Requirements

### Requirement: Описание API связей в файлах draw.io

Экспорт в `.drawio` и копирование в буфер обмена SHALL записывать описание API связи атрибутом `codrawApi` элемента
`<object>`, в который обёрнута её ячейка, и SHALL NOT писать его в строку стиля. Импорт файла и вставка фрагмента
draw.io SHALL делать атрибут `codrawApi` `<object>` и `<UserObject>` описанием API элемента; значение, которое CoDraw
не может разобрать, SHALL отбрасываться.

#### Scenario: Туда и обратно

- **WHEN** доску со связью с описанием `POST /payments` экспортируют в `.drawio` и импортируют в новую доску
- **THEN** у связи новой доски то же описание, а в файле ячейка связи обёрнута в `<object codrawApi="…">`
