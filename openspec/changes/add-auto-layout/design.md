# Design

## Context

Редактор — maxGraph поверх документа Yjs: изменение геометрии ячеек в одном `batchUpdate` становится одной
транзакцией документа и одним шагом отмены, а остальные участники получают его как любую правку. Таблица — ячейка со
стопкой полей (`childLayout: stackLayout`), группа — прозрачный контейнер, у детей которого координаты относительно
группы. Рамки («Граница», `c4-boundary`, `kubernetes-cluster`) — обычные фигуры без родства с фигурами внутри: внутри
они только по координатам и пропускают щелчки (`pointerEvents: false`). Связи — `orthogonalEdgeStyle`, maxGraph сам
прокладывает их между концами, а точки изгиба в геометрии связи — подсказки маршрута.

## Goals / Non-Goals

**Goals:**

- Раскладка слоями в двух направлениях для страницы и для выделенного, понятная для схем архитектуры и ER.
- Рамки, таблицы и группы ведут себя как целое; раскладка — один шаг отмены у того, кто её сделал.

**Non-Goals:**

- Маршруты связей от ELK (изгибы) — maxGraph прокладывает связи сам; порты по полям таблиц.
- Другие алгоритмы (дерево, круг, силовая раскладка), настройки отступов, анимация.
- Раскладка внутри группы.

## Decisions

### ELK Layered через `elkjs`, загружаемый по требованию

- Алгоритм Sugiyama из ELK: слои, минимум пересечений, выравнивание узлов, иерархия (составные узлы) — то, что нужно
  для схем со связями и рамками. `elkjs` — ELK, собранный в JavaScript, его использует, например, Mermaid.
- Альтернативы: `@dagrejs/dagre` (MIT, меньше, но слабее с составными узлами и почти не развивается); раскладки
  maxGraph (`HierarchicalLayout`) — старые алгоритмы draw.io, без рамок по координатам. Решение — в ADR-0003.
- `elkjs` весит около 1,6 МБ (460 КБ gzip): модуль грузится `import()` при первой раскладке, отдельным чанком, и не замедляет
  открытие доски. Расчёт идёт в основном потоке: для схем в сотни фигур он занимает доли секунды.
- Лицензия EPL-2.0: библиотека используется без изменений как зависимость npm; изменения в самой ELK пришлось бы
  публиковать.

### Модель → граф ELK → геометрия

- Узлы — фигуры верхнего уровня страницы (или выделенные): поле заменяется своей таблицей, фигура группы — группой.
  Размер узла — размер фигуры. Связи — между узлами раскладки, с концами, поднятыми до узлов; петли и связи с концом
  вне раскладки не учитываются.
- Рамка в раскладке — составной узел ELK: в неё входят фигуры раскладки, центр которых лежит внутри рамки (внутри
  самой маленькой из подходящих рамок). Отступы рамки: сверху 40 (подпись), с остальных сторон 20. Рамка без фигур —
  обычный узел. `hierarchyHandling: INCLUDE_CHILDREN` — связи между фигурами разных рамок учитываются при раскладке.
- Настройки: `elk.direction` `RIGHT` или `DOWN`, `spacing.nodeNode` 40, `layered.spacing.nodeNodeBetweenLayers` 80,
  `spacing.componentComponent` 60; несвязанные части раскладываются рядом.
- Результат сдвигается так, чтобы левый верхний угол разложенного совпал с прежним. Новые координаты, размеры рамок
  и пустые точки изгиба связей между разложенными фигурами записываются в одном `batchUpdate`.
- Раскладка асинхронна (загрузка модуля, расчёт ELK). Если за это время страница изменилась так, что фигур
  раскладки больше нет, она применяется к оставшимся.

### Где команда

- Кнопка «Автораскладка» на панели инструментов у участников, которые правят доску, всегда (а не только при
  выделении): без выделения раскладывается вся страница. В окне кнопки — «Слева направо» и «Сверху вниз» и подпись,
  что будет разложено: «Выделенное» или «Вся страница».
- `Mod+Shift+L` — «Слева направо», в справке по клавишам в группе «Выделение и перемещение».

## Risks / Trade-offs

- [Большие страницы] → ELK справляется с тысячами узлов, но расчёт в основном потоке на тысячах фигур может занять
  секунды; кнопка показывает, что раскладка идёт, и не запускает вторую. Перенос в Web Worker — позже.
- [Связи без изгибов после раскладки] → maxGraph прокладывает ортогональные связи сам; ручные изгибы между
  разложенными фигурами теряются, это ожидаемо после перестановки и отменяется Ctrl+Z.
- [Размер бандла] → отдельный чанк, грузится только при раскладке.
